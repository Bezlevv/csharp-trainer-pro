# Разбор кода — Модуль 26: Производительность

## Пример 1: Оптимизация без замеров

**Проблема:** меняем «что-то» наугад, не зная узкое место.
**Как надо:** сначала профилирование/бенчмарк — потом правка.

## Пример 2: string += в цикле

```csharp
string s = "";
for (int i = 0; i < 100000; i++) s += i;
```

**Проблема:** каждая конкатенация создаёт новую строку — O(n²) памяти/времени.
**Как надо:** StringBuilder.

## Пример 3: List.Contains в горячем цикле

```csharp
bool found = false;
foreach (var x in bigList)
    if (otherList.Contains(x)) { found = true; break; }
```

**Проблема:** O(n²).
**Как надо:** HashSet → O(n).

## Пример 4: Замеры в Debug

**Проблема:** Debug-сборка — без оптимизаций, цифры нерепрезентативны.
**Как надо:** Release.

## Вывод
Измеряй (BenchmarkDotNet/Stopwatch в Release), ищи O(n²)/строки/аллокации и переводи в эффективные структуры. Не оптимизируй вслепую.
