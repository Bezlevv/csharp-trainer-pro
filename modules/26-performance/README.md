# Модуль 26: Производительность .NET и BenchmarkDotNet

> **Цель:** научиться находить узкие места и измерять производительность, не полагаясь на «чутьё».

## Зачем это нужно
Оптимизировать «на глаз» — плохо. Нужно измерять. BenchmarkDotNet — стандарт бенчмарков в .NET: он аккуратно замеряет время и память, чтобы ты принимал решения на цифрах.

## Теория

### 1. Сначала измеряй
Не оптимизируй заранее. Сначала найди реальное узкое место (профилирование, бенчмарк), потом меняй.

### 2. Типичные причины медлительности
| Причина | Почему |
|---|---|
| O(n²) из-за `List.Contains`/вложенных циклов | лишний перебор |
| Конкатенация строк в цикле | создаётся много промежуточных строк |
| «Тяжёлые» вызовы в цикле | повторные вычисления |
| Синхронные вызовы | блокируют поток |
| Аллокации в горячем цикле | давление на GC |

### 3. Правильные инструменты
| Инструмент | Для чего |
|---|---|
| `Stopwatch` | быстрая грубая проверка |
| BenchmarkDotNet | точные бенчмарки |
| dotnet-trace / dotnet-counters | профилирование, метрики |

### 4. Замена List.Contains на HashSet
```csharp
// Плохо: O(n²)
foreach (var x in listA)
    if (listB.Contains(x)) { }   // O(n) на каждую проверку

// Хорошо: O(n)
var setB = listB.ToHashSet();
foreach (var x in listA)
    if (setB.Contains(x)) { }
```

### 5. StringBuilder вместо конкатенации
```csharp
// Плохо (много строк):
string s = "";
for (int i = 0; i < 10000; i++) s += i;

// Хорошо:
var sb = new System.Text.StringBuilder();
for (int i = 0; i < 10000; i++) sb.Append(i);
string result = sb.ToString();
```

### 6. BenchmarkDotNet — пример
```csharp
[MemoryDiagnoser]
public class Benchmarks
{
    [Benchmark]
    public int SumList()
    {
        var list = Enumerable.Range(1, 10000).ToList();
        return list.Sum();
    }
}
```
Запуск: `dotnet run -c Release` — BenchmarkDotNet сам прогонит много раз и даст отчёт.

### 7. Асинхронность и нагрузка
Не блокируй поток (`Wait()`/`.Result`). Используй `async/await`.

## Типичные ошибки

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| Оптимизация без замеров | тратишь время не туда | сначала бенчмарк |
| Debug-сборка для замеров | нерепрезентативно | Release |
| Конкатенация в цикле | O(n²) строк | StringBuilder |
| List.Contains в цикле | O(n²) | HashSet |
