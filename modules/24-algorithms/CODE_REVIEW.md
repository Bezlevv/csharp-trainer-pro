# Разбор кода — Модуль 24: Алгоритмы

## Пример 1: List.Contains в цикле

```csharp
foreach (var x in listA)
    if (listB.Contains(x)) { /* ... */ }
```

**Проблема:** O(n²) — для каждого элемента listA проходим listB.
**Как надо:** `var setB = listB.ToHashSet();` и `setB.Contains(x)` → O(n).

## Пример 2: Бинарный поиск по несортированному

**Проблема:** результат неверен.
**Как надо:** массив обязан быть отсортирован; проверяй или сортируй.

## Пример 3: Двойной цикл вместо Dictionary

**Проблема:** поиск пары — O(n²).
**Как надо:** использовать `Dictionary`/`HashSet` для O(n).

## Пример 4: Пузырьковая сортировка в проде

**Проблема:** O(n²), медленно на больших данных.
**Как надо:** `Array.Sort` или `OrderBy` (O(n log n)). Пузырьковую — только для обучения.

## Вывод
Выбор структуры данных определяет сложность. Думай «что я делаю: ищу, сравниваю, храню уникально?» и выбирай Dictionary/HashSet/Stack/Queue осознанно.
