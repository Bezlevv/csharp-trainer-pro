# Модуль 24: Алгоритмы и структуры данных

> **Цель:** освоить базовые алгоритмы и структуры данных, которые спрашивают на собеседованиях и которые реально нужны в работе.

## Зачем это нужно
Понимание алгоритмов — как знание грамматики для писателя. Даже если ты не пишешь сортировки каждый день, ты обязан уметь выбрать подходящую структуру данных и понимать сложность (O-нотацию).

## Теория

### 1. Сложность алгоритмов (Big O)
Big O описывает, как растёт время работы при росте входных данных:

| Запись | Смысл | Пример |
|---|---|---|
| O(1) | константное время | доступ по индексу, поиск в Dictionary |
| O(log n) | логарифмическое | бинарный поиск |
| O(n) | линейное | проход по массиву |
| O(n log n) | почти линейное | быстрая сортировка |
| O(n²) | квадратичное | вложенные циклы |

### 2. Массив vs Список
- Массив — фиксированный размер, быстрый доступ по индексу O(1).
- `List<T>` — динамический (внутри массив), добавление в конец O(1) в среднем.

### 3. Линейный поиск
```csharp
int LinearSearch(int[] arr, int target)
{
    for (int i = 0; i < arr.Length; i++)
        if (arr[i] == target) return i;
    return -1;
}
```
O(n). Работает на любом массиве.

### 4. Бинарный поиск (только отсортированный)
```csharp
int BinarySearch(int[] sorted, int target)
{
    int left = 0, right = sorted.Length - 1;
    while (left <= right)
    {
        int mid = left + (right - left) / 2;
        if (sorted[mid] == target) return mid;
        if (sorted[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```
O(log n). Массив обязан быть отсортирован.

### 5. Пузырьковая сортировка (для понимания)
```csharp
void BubbleSort(int[] arr)
{
    for (int i = 0; i < arr.Length - 1; i++)
        for (int j = 0; j < arr.Length - 1 - i; j++)
            if (arr[j] > arr[j + 1])
                (arr[j], arr[j + 1]) = (arr[j + 1], arr[j]);
}
```
O(n²). На практике используют встроенные `Array.Sort`/`OrderBy` (O(n log n)).

### 6. Структуры данных, которые нужно знать

| Структура | Особенности | Когда |
|---|---|---|
| `List<T>` | динамический массив, доступ по индексу | хранение последовательности |
| `Dictionary<K,V>` | ключ→значение O(1) | поиск по ключу |
| `HashSet<T>` | уникальность, O(1) | проверка «есть ли» |
| `Stack<T>` | LIFO | «назад», скобки |
| `Queue<T>` | FIFO | очередь задач |
| `LinkedList<T>` | быстрое вставление в середину | редкие, специальные случаи |

### 7. Пример: проверка скобок через Stack
```csharp
bool IsBalanced(string s)
{
    var stack = new Stack<char>();
    foreach (char c in s)
    {
        if (c is '(' or '[' or '{') stack.Push(c);
        else if (c is ')' or ']' or '}')
        {
            if (stack.Count == 0) return false;
            if ((stack.Pop(), c) is ('(', ')') or ('[', ']') or ('{', '}')) continue;
            return false;
        }
    }
    return stack.Count == 0;
}
```

## Типичные ошибки

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| Бинарный поиск по несортированному массиву | результат неверен | сортируй заранее |
| Двойной цикл там, где можно Dictionary | O(n²) вместо O(n) | думай о структуре |
| `List.Contains` в цикле | O(n²) | `HashSet` |
| Забыть про half-open интервал в бинарном поиске | зацикливание | аккуратно с `mid` |
