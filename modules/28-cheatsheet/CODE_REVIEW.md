# Разбор кода — Модуль 28: Шпаргалка

## Пример 1: dotnet test не видит тесты

**Проблема:** тестовый проект не добавлен в решение.
**Как надо:** `dotnet sln add ...`.

## Пример 2: Первый push без -u

**Проблема:** ветка не отслеживается.
**Как надо:** `git push -u origin main`.

## Пример 3: Миграция «не найдена»

**Проблема:** не установлен dotnet-ef.
**Как надо:** `dotnet tool install --global dotnet-ef`.

## Вывод
Шпаргалка — это то, что реально используется каждый день. Держи её под рукой, пока команды не войдут в привычку.
