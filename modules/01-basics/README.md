# Модуль 01: Основы синтаксиса

> **Цель:** уверенно работать с типами данных, переменными, операторами, преобразованием типов и строками.

## Зачем это нужно

Данные — это сердце любой программы. Пока ты не понимаешь типы, переменные и строки, невозможно решить ни одну реальную задачу: считать зарплату, обработать ввод пользователя, прочитать файл, отправить запрос. Этот модуль — фундамент, на котором строится весь язык. Здесь мы закладываем «мускулы»: к концу модуля ты свободно будешь манипулировать числами и текстом.

## Теория

### 1. Типы данных

В C# каждая переменная имеет **тип**. Тип определяет: что можно в неё хранить, сколько памяти она занимает и какие операции с ней разрешены.

#### Типы значений (value types)

Значение хранится **напрямую** в переменной.

| Тип | Размер | Диапазон / значение | Когда использовать |
|---|---|---|---|
| `int` | 4 байта | −2 147 483 648 … 2 147 483 647 | целые числа, счётчики, индексы |
| `long` | 8 байт | ~±9.2 × 10¹⁸ | очень большие целые |
| `short` | 2 байта | −32 768 … 32 767 | редкий, для экономии памяти |
| `byte` | 1 байт | 0 … 255 | байты, битовые маски |
| `double` | 8 байт | ±1.5 × 10⁻⁴⁵ … 3.4 × 10³⁸ | обычные дробные числа (по умолчанию) |
| `float` | 4 байта | ~±3.4 × 10³⁸ | дробные, когда критична память |
| `decimal` | 16 байт | ±7.9 × 10⁻²⁸ … 7.9 × 10²⁸ | деньги, точные вычисления |
| `bool` | 1 байт | `true` / `false` | флаги, условия |
| `char` | 2 байта | один символ Unicode | одиночные символы |

**Самое важное про `double` и `decimal`:**

```csharp
double a = 0.1 + 0.2;
Console.WriteLine(a); // 0.30000000000000004 (!)
```

Дробные числа хранятся в двоичном виде, поэтому `0.1 + 0.2` даёт «хвост». Для денег и точных расчётов используй `decimal`:

```csharp
decimal price = 19.99m;
decimal discount = 0.15m;
Console.WriteLine(price * (1 - discount));
```

#### Ссылочные типы (reference types)

Переменная хранит **ссылку** на объект в памяти. К ним относятся `string`, массивы, классы.

| Тип | Когда использовать |
|---|---|
| `string` | текст, строки |
| массивы `[]` | фиксированный набор однотипных элементов |

### 2. Переменные

Объявление и инициализация:

```csharp
int age = 30;              // тип указан явно
var name = "Иван";         // var — тип определяется по значению
```

`var` — не «тип без типа», а просто сокращение: компилятор сам подставляет тип. Используй `var`, когда тип очевиден из правой части (например, `var list = new List<int>();`), и явный тип — когда важна читаемость.

**Константы:**

```csharp
const double Pi = 3.14159;  // нельзя изменить после объявления
```

### 3. Правила именования

| Конвенция | Где используется | Пример |
|---|---|---|
| `PascalCase` | классы, методы, свойства | `CalculateArea`, `UserProfile` |
| `camelCase` | локальные переменные, параметры | `totalPrice`, `userAge` |
| `UPPER_CASE` / `PascalCase` | константы | `PI`, `MaxRetries` |

Имена должны быть осмысленными. `int x = 5;` — плохо. `int userAge = 5;` — хорошо.

### 4. Операторы

**Арифметика:** `+`, `-`, `*`, `/`, `%` (остаток от деления).

```csharp
int a = 17, b = 5;
Console.WriteLine(a / b);  // 3 (целочисленное деление!)
Console.WriteLine(a % b);  // 2 (остаток)
```

Обрати внимание: `17 / 5` даёт `3`, а не `3.4`, потому что оба числа целые. Чтобы получить дробный результат, хотя бы один операнд должен быть дробным.

**Сравнение:** `==`, `!=`, `<`, `>`, `<=`, `>=`.

**Логические:** `&&` (и), `||` (или), `!` (не).

```csharp
bool isAdult = age >= 18 && age < 65;
bool isHoliday = day == "Сб" || day == "Вс";
```

**Инкремент/декремент:** `++`, `--`.

```csharp
int counter = 5;
counter++;        // counter == 6
Console.WriteLine(counter++); // выведет 6, потом counter станет 7
Console.WriteLine(++counter); // counter станет 8, потом выведет 8
```

**Оператор `??` (null-coalescing):** возвращает правую часть, если левая равна `null`.

```csharp
string name = Console.ReadLine() ?? "Гость";
```

**Оператор `?.` (null-conditional):** безопасно обращается к члену, если объект не `null`.

```csharp
string? s = null;
int? length = s?.Length;  // null, не исключение
```

### 5. Приведение типов

**Неявное** — когда данные не теряются:

```csharp
int small = 10;
long big = small;         // неявно: int в long безопасно
```

**Явное** — когда может быть потеря данных:

```csharp
double d = 9.7;
int i = (int)d;           // 9, дробная часть отбрасывается
```

**Проверка переполнения:**

```csharp
checked
{
    int x = int.MaxValue;
    int y = x + 1;        // OverflowException
}
```

### 6. Преобразование строк в числа

Самый безопасный способ — `TryParse`:

```csharp
if (int.TryParse(input, out int number))
{
    Console.WriteLine($"Число: {number}");
}
else
{
    Console.WriteLine("Это не число");
}
```

Ошибки, которые ловят `Parse` → исключения, обрабатываются конструкциями try-catch (модуль 08), но для ввода от пользователя `TryParse` удобнее.

### 7. Строки

**Интерполяция `$`** — основной способ собрать строку:

```csharp
string name = "Мария";
int age = 28;
Console.WriteLine($"{name}, тебе {age} лет.");
```

**Вербатим `@`** — строка с буквальными переводами строк и без экранирования:

```csharp
string path = @"C:\Users\ivan\file.txt";
string text = @"Первая строка
Вторая строка";
```

**Строки неизменяемы (immutable):** любая операция «изменения» создаёт новую строку. Это важно для памяти и производительности (детальнее — в разборе кода).

**Популярные методы:**

```csharp
string s = "Hello, World!";
Console.WriteLine(s.Length);          // 13
Console.WriteLine(s.ToUpper());       // "HELLO, WORLD!"
Console.WriteLine(s.Substring(7));    // "World!"
Console.WriteLine(s.IndexOf("o"));    // 4
Console.WriteLine(s.Replace("World", "C#")); // "Hello, C#!"
var parts = s.Split(", ");            // ["Hello", "World!"]
```

**Сравнение строк:**

```csharp
string a = "Привет";
string b = "привет";
Console.WriteLine(a == b);                      // false (регистр важен)
Console.WriteLine(a.Equals(b, StringComparison.OrdinalIgnoreCase)); // true
```

### 8. Ввод и вывод

```csharp
Console.Write("Введи имя: ");
string name = Console.ReadLine() ?? "";
Console.WriteLine($"Привет, {name}!");
```

Парсинг чисел с учётом культуры:

```csharp
double d = double.Parse("3,5", System.Globalization.CultureInfo.InvariantCulture);
```

## Типичные ошибки

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| `double` для денег | Потеря точности из-за округлений | `decimal` |
| `17 / 5` ожидаем `3.4` | Целочисленное деление отбрасывает остаток | один из операндов — дробный: `17.0 / 5` |
| `int.Parse` без обработки | Программа падает при неверном вводе | `TryParse` |
| Склейка строк `"a" + b + "c"` | Нечитаемо; при многих операциях — медленно | интерполяция `$""` |
| Имена `x`, `y`, `temp` | Через месяц никто не поймёт код | осмысленные имена |
