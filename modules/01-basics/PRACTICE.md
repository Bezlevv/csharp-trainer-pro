# Практика — Модуль 01

> Сначала попробуй решить сам. Подсказка — если застрял. Решение — в конце файла, в свёрнутом блоке.

## Задача 1: Калькулятор

**Сложность:** ★☆☆
**Описание:** Напиши простейший калькулятор: два числа и операция (`+`, `-`, `*`, `/`). Если операция неверная — выведи сообщение об ошибке.

**Требования:**
- Считай два числа через `double.TryParse`.
- Считай операцию через `Console.ReadLine()`.
- Используй `switch` для выбора действия.

**Пример вывода:**

```
Введите первое число: 10
Введите второе число: 4
Введите операцию (+ - * /): /
Результат: 2,5
```

## Задача 2: Конвертер температур

**Сложность:** ★☆☆
**Описание:** Переведи температуру из Цельсия в Фаренгейты и обратно.

**Требования:**
- Формула: F = C × 9/5 + 32; C = (F − 32) × 5/9.
- Спроси направление конвертации (C→F или F→C), затем значение.
- Выведи результат с округлением до 2 знаков: `F2`.

**Подсказка:** «F2» в интерполяции — `$"{value:F2}"`.

## Задача 3: Подсчёт символов

**Сложность:** ★☆☆
**Описание:** Прими строку и выведи её длину, а также количество букв 'a' (без учёта регистра).

**Требования:**
- Используй `.Length` и, например, `.ToLower()` + `IndexOf` в цикле (или `Count`, если знаешь LINQ).
- Выведи оба числа.

## Задача 4: Шифр Цезаря

**Сложность:** ★★☆
**Описание:** Реализуй шифр Цезаря для английских строчных букв: каждая буква сдвигается на `shift` позиций в алфавите.

**Требования:**
- Прими строку и число сдвига.
- Обрабатывай `a`…`z` (строчные). Остальные символы оставляй как есть.
- Циклический сдвиг: `z` + 1 → `a`.

**Подсказка:** использовать `(char)('a' + (ch - 'a' + shift) % 26)`.

## Задача 5: Безопасный ввод числа

**Сложность:** ★★☆
**Описание:** Напиши функцию (или повторяющийся блок), которая запрашивает число, пока пользователь не введёт корректное значение.

**Требования:**
- Используй `double.TryParse` в цикле `while`.
- При неверном вводе выводи сообщение и запрашивай снова.

**Пример вывода:**

```
Введите число: abc
Некорректное число, попробуйте ещё раз.
Введите число: 42
Спасибо, число: 42
```

## Задача 6: Разбор даты

**Сложность:** ★★☆
**Описание:** Прими строку формата `ГГГГ-ММ-ДД` (например, `2024-01-15`) и выведи день, месяц и год отдельно.

**Требования:**
- Используй `Split('-')`.
- Выведи: `Год: 2024, Месяц: 01, День: 15`.

**Подсказка:** `Split` возвращает массив строк; индексируй его `parts[0]`, `parts[1]`, `parts[2]`.

## Решения

<details>
<summary>Задача 1 — решение</summary>

```csharp
Console.Write("Введите первое число: ");
double.TryParse(Console.ReadLine(), out double a);

Console.Write("Введите второе число: ");
double.TryParse(Console.ReadLine(), out double b);

Console.Write("Введите операцию (+ - * /): ");
string op = Console.ReadLine() ?? "";

double result = op switch
{
    "+" => a + b,
    "-" => a - b,
    "*" => a * b,
    "/" => b != 0 ? a / b : double.NaN,
    _ => double.NaN
};

Console.WriteLine(result == double.NaN ? "Ошибка" : $"Результат: {result}");
```

**Пояснение:** `switch`-выражение сопоставляет строку операции с шаблонами. `_` — шаблон по умолчанию. `double.NaN` — «не число», удобный маркер ошибки.

</details>

<details>
<summary>Задача 2 — решение</summary>

```csharp
Console.Write("Направление (C->F или F->C): ");
string dir = (Console.ReadLine() ?? "").Trim().ToLower();

Console.Write("Введите значение: ");
double.TryParse(Console.ReadLine(), out double value);

double result = dir switch
{
    "c->f" => value * 9 / 5 + 32,
    "f->c" => (value - 32) * 5 / 9,
    _ => double.NaN
};

Console.WriteLine(result == double.NaN ? "Неверное направление" : $"Результат: {result:F2}");
```

**Пояснение:** `.Trim().ToLower()` нормализует ввод (`C->F` → `c->f`). `:F2` округляет до двух знаков.

</details>

<details>
<summary>Задача 3 — решение</summary>

```csharp
Console.Write("Введите строку: ");
string input = Console.ReadLine() ?? "";

int aCount = 0;
foreach (char ch in input.ToLower())
{
    if (ch == 'a') aCount++;
}

Console.WriteLine($"Длина: {input.Length}, букв 'a': {aCount}");
```

**Пояснение:** `foreach` перебирает символы строки. Количество `'a'` считаем по строке, приведённой к нижнему регистру — так регистр не мешает.

</details>

<details>
<summary>Задача 4 — решение</summary>

```csharp
Console.Write("Введите строку: ");
string input = Console.ReadLine() ?? "";

Console.Write("Сдвиг: ");
int.TryParse(Console.ReadLine(), out int shift);

string result = "";
foreach (char ch in input)
{
    if (ch >= 'a' && ch <= 'z')
    {
        char shifted = (char)('a' + (ch - 'a' + shift) % 26);
        result += shifted;
    }
    else
    {
        result += ch;
    }
}

Console.WriteLine($"Зашифровано: {result}");
```

**Пояснение:** `ch - 'a'` даёт позицию буквы (0–25). Прибавляем сдвиг, берём `% 26` для цикличности. `result +=` в цикле — допустимо для учебного примера, на практике лучше `StringBuilder` (подробности — в разборе кода).

</details>

<details>
<summary>Задача 5 — решение</summary>

```csharp
double GetNumberFromUser()
{
    while (true)
    {
        Console.Write("Введите число: ");
        if (double.TryParse(Console.ReadLine(), out double value))
        {
            return value;
        }
        Console.WriteLine("Некорректное число, попробуйте ещё раз.");
    }
}

double number = GetNumberFromUser();
Console.WriteLine($"Спасибо, число: {number}");
```

**Пояснение:** `while (true)` + `return` изнутри — безопасный способ повторять запрос до успеха. Это паттерн «guard clause наоборот»: пока условие не выполнено, повторяем.

</details>

<summary>Задача 6 — решение</summary>

```csharp
Console.Write("Введите дату (ГГГГ-ММ-ДД): ");
string input = Console.ReadLine() ?? "";

string[] parts = input.Split('-');

if (parts.Length == 3)
{
    Console.WriteLine($"Год: {parts[0]}, Месяц: {parts[1]}, День: {parts[2]}");
}
else
{
    Console.WriteLine("Неверный формат даты");
}
```

**Пояснение:** `Split('-')` разбивает строку на части. Проверка `parts.Length == 3` защищает от неверного формата. (В реальности лучше `DateTime.TryParseExact`, но это будет позже, в модуле 12.)

</details>
