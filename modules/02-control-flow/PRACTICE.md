## Задача 1: FizzBuzz

**Сложность:** ★☆☆
**Описание:** Для чисел от 1 до 100 выведи: число, если оно не делится ни на 3, ни на 5; `Fizz`, если делится на 3; `Buzz`, если на 5; `FizzBuzz`, если на оба.

**Требования:**
- Используй `for` и `%` (остаток от деления).
- Порядок проверок важен: сначала «делится на 15».

## Задача 2: Таблица умножения

**Сложность:** ★☆☆
**Описание:** Выведи таблицу умножения от 1 до 10 (10 строк по 10 столбцов).

**Требования:**
- Используй вложенные циклы.
- Форматируй вывод, чтобы столбцы были ровными: `$"{product,4}"`.

## Задача 3: Игра «Угадай число»

**Сложность:** ★★☆
**Описание:** Компьютер загадывает число от 1 до 100. Пользователь угадывает, программа подсказывает «больше»/«меньше». Даётся 7 попыток.

**Требования:**
- `Random` для загадывания: `Random.Shared.Next(1, 101)`.
- `while` с счётчиком попыток и `break` при угадывании.

**Пример вывода:**

```
Загадано число от 1 до 100. Попробуй угадать за 7 попыток.
Попытка 1: 50
Больше.Попытка 2: 75
Меньше.
Попытка 3: 62
Поздравляю! Угадал с 3 попытки!
```

## Задача 4: Сумма цифр числа

**Сложность:** ★☆☆
**Описание:** Посчитай сумму цифр целого положительного числа.

**Требования:**
- Используй `% 10` и `/ 10`, чтобы «откусывать» цифры.
- Пример: `123` → `1 + 2 + 3 = 6`.

**Подсказка:** Строковый способ (`n.ToString().Sum(...)`) тоже допустим, но попробуй арифметический.

## Задача 5: Пирамида из символов

**Сложность:** ★★☆
**Описание:** Выведи пирамиду из `*` высотой N (вводится с клавиатуры).

**Требования:**
- На высоте 3:
  ```
    *
   ***
  *****
  ```
- Используй вложенные циклы для пробелов и звёздочек.

## Задача 6: Поиск простых чисел (решето)

**Сложность:** ★★★
**Описание:** Найди все простые числа до N (вводится с клавиатуры) и выведи их.

**Требования:**
- Используй решето Эратосфена: массив `bool`, постепенное «вычёркивание».
- Ограничение: N от 2 до 1000.

<details>
<summary>Задача 1 — решение</summary>

```csharp
for (int i = 1; i <= 100; i++)
{
    if (i % 15 == 0)
    {
        Console.WriteLine("FizzBuzz");
    }
    else if (i % 3 == 0)
    {
        Console.WriteLine("Fizz");
    }
    else if (i % 5 == 0)
    {
        Console.WriteLine("Buzz");
    }
    else
    {
        Console.WriteLine(i);
    }
}
```

**Пояснение:** Проверка `i % 15 == 0` обязательно первой — иначе `Fizz` или `Buzz` «перехватят» число, делящееся и на 3, и на 5.

</details>

<summary>Задача 2 — решение</summary>

```csharp
for (int i = 1; i <= 10; i++)
{
    for (int j = 1; j <= 10; j++)
    {
        Console.Write($"{i * j,4}");
    }
    Console.WriteLine();
}
```

**Пояснение:** Ширина `4` в интерполяции выравнивает вывод по правому краю. Вложенный цикл по `j` — внутренний, он быстрее меняется.

</details>

<details>
<summary>Задача 3 — решение</summary>

```csharp
int secret = Random.Shared.Next(1, 101);
Console.WriteLine("Загадано число от 1 до 100. Попробуй угадать за 7 попыток.");

for (int attempt = 1; attempt <= 7; attempt++)
{
    Console.Write($"Попытка {attempt}: ");
    int.TryParse(Console.ReadLine(), out int guess);

    if (guess == secret)
    {
        Console.WriteLine($"Поздравляю! Угадал с {attempt} попытки!");
        return;
    }

    Console.WriteLine(guess < secret ? "Больше." : "Меньше.");
}

Console.WriteLine($"Попытки кончились. Было загадано: {secret}");
```

**Пояснение:** `Random.Shared` — потокобезопасный общий генератор. `return` в `Main` (top-level) завершает программу.

</details>

<details>
<summary>Задача 4 — решение</summary>

```csharp
Console.Write("Введите число: ");
int.TryParse(Console.ReadLine(), out int n);

int sum = 0;
int remaining = Math.Abs(n);

while (remaining > 0)
{
    sum += remaining % 10;
    remaining /= 10;
}

Console.WriteLine($"Сумма цифр: {sum}");
```

**Пояснение:** `remaining % 10` — последняя цифра; `remaining /= 10` отбрасывает её. `Math.Abs` справляется с отрицательными числами.

</details>

<details>
<summary>Задача 5 — решение</summary>

```csharp
Console.Write("Высота пирамиды: ");
int.TryParse(Console.ReadLine(), out int n);

for (int row = 1; row <= n; row++)
{
    // пробелы слева
    for (int space = 0; space < n - row; space++)
    {
        Console.Write(" ");
    }

    // звёздочки
    for (int star = 0; star < 2 * row - 1; star++)
    {
        Console.Write("*");
    }

    Console.WriteLine();
}
```

**Пояснение:** Пробелов: `n - row`. Звёздочек: `2 * row - 1`. Оба внутренних цикла зависят от строки `row`.

</details>

<summary>Задача 6 — решение</summary>

```csharp
Console.Write("До какого числа искать простые? ");
int.TryParse(Console.ReadLine(), out int n);

var isPrime = new bool[n + 1];
Array.Fill(isPrime, true);
isPrime[0] = isPrime[1] = false;

for (int i = 2; i * i <= n; i++)
{
    if (isPrime[i])
    {
        for (int j = i * i; j <= n; j += i)
        {
            isPrime[j] = false;
        }
    }
}

Console.WriteLine("Простые числа:");
for (int i = 2; i <= n; i++)
{
    if (isPrime[i]) Console.Write($"{i} ");
}
Console.WriteLine();
```

**Пояснение:** Решето Эратосфена. Идём от 2; если `i` простое, вычёркиваем все его кратные начиная с `i*i`. Массив `bool` индексируется числом. `Array.Fill` заполняет массив одним значением.

</details>
