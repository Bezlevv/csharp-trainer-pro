# Практика — Модуль 15

> Итоговые задания на расширение Task Tracker. Работаем в папке `task-tracker`.

## Задача 1: Поиск по названию

**Сложность:** ★★☆
**Описание:** Добавь в меню пункт «Поиск по названию».

**Требования:**
- Метод `TaskService.FindByTitleAsync(string query)` — поиск по подстроке (без учёта регистра).
- В `ConsoleUI` — пункт меню и ввод запроса.

## Задача 2: Категории

**Сложность:** ★★★
**Описание:** Добавь задачи поле `Category`.

**Требования:**
- `string Category { get; init; } = "Общее";`.
- Фильтр по категории в `GetAsync`.

## Задача 3: Статистика за неделю

**Сложность:** ★★★
**Описание:** Добавь «Сколько задач завершено за неделю».

**Требования:**
- Метод `TaskService.GetDoneCountSinceAsync(DateTime since)`.
- В UI — пункт меню.

## Задача 4: Экспорт в CSV

**Сложность:** ★★★
**Описание:** Экспортируй задачи в `export.csv`.

**Требования:**
- Заголовок: `Id;Title;Status;Priority;Deadline`.
- Вывод пути к файлу.

## Задача 5: Рефакторинг времени

**Сложность:** ★★★
**Описание:** Замени прямой `DateTime.UtcNow` в `TaskService` на абстракцию `IClock`.

**Требования:**
- `interface IClock { DateTime UtcNow { get; } }`.
- Конструкторная инъекция.
- Обнови тесты на `FakeClock` (как в модуле 13).

## Задача 6: Своё расширение

**Сложность:** ★★★
**Описание:** Придумай и реализуй одну функцию «под себя» (теги, повторяющиеся задачи, заметки).

**Требования:**
- Новый пункт меню.
- Не менее одного нового юнит-теста.

## Подсказки

- Модель `TaskItem` — `record`: чтобы изменить поле, используй `with` (как в `CompleteAsync`).
- Репозиторий тестируется через `InMemoryTaskRepository` (есть в тестах).
- Не забывай `TreatWarningsAsErrors` — код обязан собираться без предупреждений.
