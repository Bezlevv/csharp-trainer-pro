# Разбор кода — Модуль 25: Микросервисы

## Пример 1: Синхронная цепочка

```csharp
orderService.Create(order);
paymentService.Pay(order.Id);      // ждём
inventoryService.Reserve(order.Id); // ждём
emailService.Send(order.Id);         // ждём
```

**Проблема:** медленно, любой сбой ломает всю цепочку, сервисы жёстко связаны.
**Как надо:** событийный подход: `Create` публикует `OrderCreated`, а остальные слушают независимо.

## Пример 2: Потеря сообщений

**Проблема:** если получатель упал после получения, но до обработки — сообщение потеряно.
**Как надо:** подтверждать обработку (ack), повторные попытки, dead-letter очередь.

## Пример 3: Неидемпотентный обработчик

```csharp
void OnOrderCreated(string id) { deductMoney(id); } // повторно — дважды спишет
```

**Как надо:** перед действием проверять, обработан ли id.

## Вывод
Микросервисы — про независимость и событийную связь. Всегда думай о надёжности (повторы, идемпотентность) и не усложняй без необходимости.
