# Практика — Модуль 00

> Сначала попробуй решить сам. Подсказка — если застрял. Решение — в конце файла, в свёрнутом блоке.

## Задача 1: Первая программа через CLI

**Сложность:** ★☆☆
**Описание:** Создай проект через терминал, запусти его, затем измени текст приветствия.

**Требования:**
- Создай проект командой `dotnet new console -n MyFirstApp`.
- Запусти его (`dotnet run`), убедись, что видишь `Hello, World!`.
- Измени текст на `Привет из C#!` и запусти снова.

**Подсказка:** После изменения `Program.cs` не забудь пересобрать — `dotnet run` это сделает автоматически.

## Задача 2: Анкета

**Сложность:** ★☆☆
**Описание:** Напиши программу-анкету: узнай имя, возраст и город, затем выведи приветствие с этими данными.

**Требования:**
- Считывай три значения через `Console.ReadLine()`.
- Выведи одно предложение с использованием интерполяции `$""`.

**Пример вывода:**

```
Как тебя зовут? Иван
Сколько тебе лет? 25
В каком городе ты живёшь? Москва
Привет, Иван из Москвы! Тебе 25 лет.
```

## Задача 3: Подключение пакета NuGet

**Сложность:** ★★☆
**Описание:** Подключи пакет `Humanizer` и используй его для «очеловечивания» чисел.

**Требования:**
- Подключи пакет командой `dotnet add package Humanizer`.
- Попробуй `(12345).ToWords()` и `12345.Ordinalize()` — пойми, что они делают.
- Выведи результаты.

**Подсказка:** Пакет подключается в `.csproj`. После этого его можно использовать в коде — добавь `using Humanizer;` в начало файла.

## Задача 4: Изучаем структуру проекта

**Сложность:** ★☆☆
**Описание:** Исследуй, что появляется после сборки.

**Требования:**
- Собери проект (`dotnet build`).
- Загляни в папки `bin/` и `obj/` — что там лежит?
- Найди `.exe` (или бинарный файл без расширения на Linux/macOS) в `bin/Debug/net8.0/`.
- Запусти этот файл напрямую, не через `dotnet run`.

**Подсказка:** Найдите в папке `bin/Debug/net8.0/` файл с именем проекта. Запусти его двойным кликом или из терминала.

## Решения

<details>
<summary>Задача 1 — решение</summary>

```bash
dotnet new console -n MyFirstApp
cd MyFirstApp
dotnet run
```

Изменяем `Program.cs`:

```csharp
Console.WriteLine("Привет из C#!");
```

**Пояснение:** `dotnet run` автоматически пересоберёт проект перед запуском, так что просто перезапусти команду.

</details>

<details>
<summary>Задача 2 — решение</summary>

```csharp
Console.Write("Как тебя зовут? ");
string name = Console.ReadLine() ?? "";

Console.Write("Сколько тебе лет? ");
int age = int.Parse(Console.ReadLine()!);

Console.Write("В каком городе ты живёшь? ");
string city = Console.ReadLine() ?? "";

Console.WriteLine($"Привет, {name} из {city}! Тебе {age} лет.");
```

**Пояснение:** `Console.ReadLine()` может вернуть `null` (например, при закрытии консоли). Оператор `?? ""` заменяет `null` на пустую строку, а `!` в `int.Parse(Console.ReadLine()!)` говорит компилятору, что значение не null.

</details>

<details>
<summary>Задача 3 — решение</summary>

```bash
dotnet add package Humanizer
```

```csharp
using Humanizer;

Console.WriteLine((12345).ToWords());        // "twelve thousand three hundred and forty-five"
Console.WriteLine(12345.Ordinalize());        // "12345th"
```

**Пояснение:** `Humanizer` — популярная библиотека для работы с читаемым текстом. `ToWords` превращает число в слова, `Ordinalize` добавляет порядковый суффикс. Это отличный пример того, как NuGet расширяет возможности платформы.

</details>

<details>
<summary>Задача 4 — решение</summary>

```bash
dotnet build
dir bin\Debug\net8.0\
```

**Пояснение:** В `bin/Debug/net8.0/` лежит исполняемый файл (на Windows — с расширением `.exe`). Его можно запустить напрямую — это «готовая программа», которую можно отдать пользователю без SDK. Папка `obj/` содержит промежуточные файлы компиляции.

</details>
