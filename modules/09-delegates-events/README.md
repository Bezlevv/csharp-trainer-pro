# Модуль 09: Делегаты, лямбды и события

> **Цель:** передавать поведение как параметр, писать компактные лямбды и строить системы уведомлений на событиях.

## Зачем это нужно

Функции в C# — это значения. Их можно передавать в методы, хранить и вызывать позже. На этой идее построены колбэки, события и LINQ. Понимание делегатов и лямбд открывает дверь к паттернам Observer, Strategy и большей части современного C# API.

## Теория

### 1. Делегаты

Делегат — тип, который описывает сигнатуру метода.

```csharp
delegate void Notify(string message);
```

Мы можем передать метод в переменную-делегат и вызвать его:

```csharp
void PrintToConsole(string msg) => Console.WriteLine(msg);

Notify notifier = PrintToConsole;
notifier("Привет");
```

Делегат можно передать как параметр другого метода — это и есть **колбэк**:

```csharp
void ExecuteAction(Notify callback)
{
    callback("Действие выполняется");
}
```

### 2. `Action`, `Func`, `Predicate`

Необязательно объявлять свой делегат — есть готовые:

| Тип | Возвращает | Пример |
|---|---|---|
| `Action` | ничего | `Action log = () => Console.WriteLine("!");` |
| `Action<T>` | ничего | `Action<string> show = s => Console.WriteLine(s);` |
| `Func<TR>` | `TR` | `Func<int> f = () => 42;` |
| `Func<T1,T2,TR>` | `TR` | `Func<int,int,int> add = (a,b) => a+b;` |
| `Predicate<T>` | `bool` | `Predicate<int> >Zero = n => n > 0;` |

### 3. Лямбда-выражения

Лямбда — анонимная функция:

```csharp
Func<int, int> square = x => x * x;
Console.WriteLine(square(5)); // 25
```

С телом из нескольких операторов:

```csharp
Action<int> showTable = n =>
{
    for (int i = 1; i <= n; i++) Console.WriteLine(i);
};
```

Лямбды повсюду в BCL:

```csharp
var numbers = new List<int> { 3, 1, 4, 1, 5 };
numbers.Sort((a, b) => b.CompareTo(a)); // по убыванию
var firstEven = numbers.Find(n => n % 2 == 0);
```

### 4. Замыкания (closures)

Лямбда «захватывает» переменные из внешнего контекста:

```csharp
int factor = 10;
Func<int, int> multiply = x => x * factor;
Console.WriteLine(multiply(5)); // 50
```

> **Важно:** захваченная переменная — по ссылке. Если она изменится позже, лямбда увидит новое значение. Это причина классической ловушки с циклом (см. разбор кода).

### 5. События

`event` — «публикация» некоего события, на которое подписываются обработчики.

```csharp
class OrderService
{
    public event EventHandler? OrderPlaced;

    public void PlaceOrder(string id)
    {
        Console.WriteLine($"Заказ {id} создан");
        OrderPlaced?.Invoke(this, EventArgs.Empty);
    }
}
```

Подписка и отписка:

```csharp
var service = new OrderService();
service.OrderPlaced += OnOrderPlaced;   // подписаться
service.OrderPlaced -= OnOrderPlaced;   // отписаться

void OnOrderPlaced(object? sender, EventArgs e)
{
    Console.WriteLine("Уведомление клиенту отправлено");
}
```

- `EventHandler` / `EventHandler<T>` — стандартные типы для событий.
- Публикация через `?.Invoke(...)` — безопасная проверка на null.

### 6. Ковариантность/контравариантность (кратко)

Делегаты позволяют подставлять более специфичные типы там, где ожидается базовый (ковариантность) и наоборот (контравариантность). Это редко нужно новичку — просто знай, что такое существует.

## Типичные ошибки

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| Делегат-поле вместо события | любой может присвоить и затереть подписчиков | `event` |
| Публикация без null-проверки | `NullReferenceException` | `Event?.Invoke(...)` |
| Лямбда вместо именованного метода, если он переиспользуется | дублирование и сложность отладки | отдельный метод |
| Замыкание на переменную цикла | неожиданные значения | запоминать значение в локальную переменную |
| `+=` одного и того же метода дважды | двойное выполнение | контролировать подписку |
