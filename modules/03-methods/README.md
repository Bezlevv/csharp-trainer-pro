# Модуль 03: Методы

> **Цель:** разбивать код на переиспользуемые методы, правильно передавать параметры и понимать область видимости.

## Зачем это нужно

Представь, что тебе нужно посчитать площадь окружности в пяти местах программы. Без методов ты напишешь одну и ту же формулу пять раз. Напишешь метод — и вызываешь его где угодно, а исправление формулы происходит в одном месте. Методы — главный инструмент **декомпозиции**: разбиения большой задачи на маленькие понятные куски.

## Теория

### 1. Зачем нужны методы

Метод — именованный именованный блок кода, который можно вызывать многократно. Зачем это нужно:

- **Переиспользование** — не дублируем код.
- **Читаемость** — имя метода объясняет, что он делает.
- **Тестируемость** — маленький метод легко проверить отдельно.

### 2. Синтаксис

```csharp
double AreaOfCircle(double radius)
{
    const double Pi = 3.14159;
    return Pi * radius * radius;
}
```

Вызов:

```csharp
double area = AreaOfCircle(5);
Console.WriteLine(area);
```

Части сигнатуры: модификатор (по умолчанию `private`), возвращаемый тип, имя, параметры в скобках, тело.

### 3. `void` — метод, ничего не возвращающий

```csharp
void PrintGreeting(string name)
{
    Console.WriteLine($"Привет, {name}!");
}
```

### 4. Параметры по значению (по умолчанию)

```csharp
void Change(int x)
{
    x = 100; // меняем копию
}

int a = 5;
Change(a);
Console.WriteLine(a); // 5 — не изменилось!
```

Для ссылочных типов (строка, объект) передаётся ссылка — но присвоение параметру новой ссылки не влияет на вызывающего.

### 5. `ref`, `out`, `in`

**`out`** — метод обязан присвоить значение параметру:

```csharp
bool TryParsePositive(string s, out int result)
{
    if (int.TryParse(s, out int value) && value > 0)
    {
        result = value;
        return true;
    }

    result = 0;
    return false;
}
```

```csharp
if (TryParsePositive("42", out int n))
{
    Console.WriteLine(n); // 42
}
```

**`ref`** — передаём по ссылке, метод может изменить оригинал:

```csharp
void Swap(ref int a, ref int b)
{
    (a, b) = (b, a);
}
```

```csharp
int x = 1, y = 2;
Swap(ref x, ref y);
Console.WriteLine($"{x} {y}"); // 2 1
```

**`in`** — ссылка только для чтения (эффективность для крупных структур), редко используется новичками.

### 6. `params` — переменное число аргументов

```csharp
int Sum(params int[] numbers)
{
    int total = 0;
    foreach (int n in numbers) total += n;
    return total;
}
```

```csharp
Console.WriteLine(Sum(1, 2, 3));     // 6
Console.WriteLine(Sum(1, 2, 3, 4, 5)); // 15
```

### 7. Именованные и необязательные параметры

```csharp
void Order(string item, int quantity = 1, string? note = null)
{
    Console.WriteLine($"{item}: x{quantity}");
    if (note is not null) Console.WriteLine($"Примечание: {note}");
}
```

```csharp
Order("Пицца");                      // quantity=1, note=null
Order("Пицца", quantity: 3, note: "Без лука"); // именованные аргументы
```

### 8. Перегрузка методов (overloading)

Одинаковое имя, разные параметры:

```csharp
int Add(int a, int b) => a + b;
double Add(double a, double b) => a + b;
int Add(int a, int b, int c) => a + b + c;
```

Компилятор выбирает подходящую перегрузку по типам аргументов.

### 9. Область видимости

```csharp
int y = 10; // видима во всём методе

void LocalScope()
{
    int x = 5; // видима только внутри LocalScope
    Console.WriteLine(x);
}
// здесь x недоступен
```

Переменные из внешних блоков (например, объявленные в `Main` до вызова) в методах не видны — в метод нужно явно передать их параметрами.

### 10. Статические методы

`static` означает: метод принадлежит типу, а не конкретному объекту. Вызывается через имя класса:

```csharp
Console.WriteLine(Math.Max(5, 10)); // Math — класс, Max — статический метод
```

В `Program` на верхнем уровне все наши методы — статические (или локальные функции, см. ниже).

**Локальные функции** — методы внутри методов, полезны для вспомогательной логики:

```csharp
int FactorialLocal(int n)
{
    int Mul(int a, int b) => a * b; // локальная функция

    int result = 1;
    for (int i = 2; i <= n; i++) result = Mul(result, i);
    return result;
}
```

### 11. Возврат нескольких значений через tuple

```csharp
(int Min, int Max) FindMinMax(int[] numbers)
{
    int min = numbers[0], max = numbers[0];
    foreach (int n in numbers)
    {
        if (n < min) min = n;
        if (n > max) max = n;
    }
    return (min, max);
}
```

```csharp
var (min, max) = FindMinMax(new[] { 3, 1, 4, 1, 5 });
Console.WriteLine($"{min}..{max}"); // 1..5
```

### 12. Рекурсия

Метод вызывает сам себя. Обязателен **базовый случай** — условие выхода.

```csharp
long Factorial(int n)
{
    if (n <= 1) return 1;        // базовый случай
    return n * Factorial(n - 1); // рекурсивный шаг
}
```

Каждый рекурсивный вызов кладётся на стек. Слишком глубокая рекурсия → `StackOverflowException`. Для факториала/Фибоначчи рекурсия красива, но, например, наивный Фибоначчи экспоненциально медленный.

### 13. Методы расширения (анонс)

Методы расширения позволяют «добавить» метод к существующему типу. Подробно разберём в модуле 10 (LINQ), а пока просто знай, что это мощный механизм C#.

## Типичные ошибки

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| Метод-«монстр» на 100 строк | Невозможно тестировать и понять | разбить на несколько маленьких методов |
| Дублирование логики в нескольких методах | Правка в одном месте забывается в другом | вынести в один общий метод |
| Нет guard clauses | Глубокая вложенность `if` | ранний `return` при неверных данных |
| `out`-параметр там, где читабельнее tuple | Код выглядит как форточка | вернуть кортеж |
| Магические значения в теле | Менять больно | параметры или именованные константы |
