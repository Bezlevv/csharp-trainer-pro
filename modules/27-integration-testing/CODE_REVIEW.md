# Разбор кода — Модуль 27: Тестирование

## Пример 1: E2E на всё

**Проблема:** сотни браузерных тестов — медленно, хрупко.
**Как надо:** пирамида: много юнит, меньше интеграционных, несколько ключевых E2E.

## Пример 2: Реальная БД в тестах

**Проблема:** тесты зависят от окружения и ломают данные.
**Как надо:** in-memory или Testcontainers (изолированный контейнер).

## Пример 3: Юнит лезет в сеть

**Проблема:** нестабильно, медленно.
**Как надо:** моки на границах.

## Вывод
Сбалансируй пирамиду: юнит-база, интеграционные на ключевые связки, минимум E2E. Изолируй внешние зависимости.
