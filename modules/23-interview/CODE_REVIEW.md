# Разбор кода — Модуль 23: Собеседование

## Пример 1: Слабый ответ про полиморфизм

«Это когда один класс наследует другой.» — слишком узко и неточно.

**Как отвечать:** «Полиморфизм — возможность одного и того же вызова вести себя по-разному для разных фактических типов. Например, виртуальный метод `Speak()` в базовом классе переопределяется наследниками; вызов через ссылку базового типа вызывает переопределённую версию. Это даёт расширяемость — новое поведение добавляется новым классом, без правки старого.»

## Пример 2: Путаница abstract class и interface

Сказать «это почти одно и то же» — плохо.

**Как отвечать:** отличия: интерфейс — только контракт (без состояния), можно реализовать много; абстрактный класс может содержать реализацию и поля, но наследование — одно. Интерфейс — про «что умеет», абстрактный класс — про «что это такое».

## Пример 3: Незнание сложности коллекций

Не знать, что `List.Contains` — O(n), а `Dictionary` — O(1) — красный флаг.

**Как запомнить:** массив/List ищут перебором (O(n)); Dictionary/HashSet используют хэш (O(1)); отсортированные — O(log n).

## Пример 4: «Я всё держу в Program.cs»

Плохо. **Как отвечать:** разделять на слои, использовать DI, тестировать.

## Вывод
Собеседование проверяет понимание, а не зубрёжку. Умей объяснять на примерах и «почему».
