# Практика — Модуль 23: Собеседование

## Задача 1: Ответь своими словами

**Сложность:** ★☆☆
**Описание:** Объясни вслух (или запиши), что такое полиморфизм.

**Требования:**
- Приведи пример с `Animal` / `Dog`.

## Задача 2: class vs struct

**Сложность:** ★★☆
**Описание:** Объясни разницу и когда что выбирать.

**Требования:**
- Тип значения vs ссылочный.
- Пример: `struct` для мелких immutable-сущностей.

## Задача 3: abstract class vs interface

**Сложность:** ★★☆
**Описание:** Составь таблицу отличий.

**Требования:**
- Наследование: 1 vs много.
- Данные/поля, конструкторы.

## Задача 4: Опиши сервис

**Сложность:** ★★★
**Описание:** Спроектируй на словах мини-сервис (заказы).

**Требования:**
- Слои, интерфейсы, DI, хранилище, тесты.

## Задача 5: Разбор типичного кода

**Сложность:** ★★★
**Описание:** Найди ошибки:
```csharp
int sum = 0;
for (int i = 0; i < 10; i++) { sum += numbers[i]; }
```
(если numbers короче 10 — исключение).

**Требования:**
- Предложи безопасный вариант (`Fixed`/проверка длины).

## Решения

<details>
<summary>Задача 1 — решение</summary>

> Полиморфизм — способность одного кода работать с разными типами через общий базовый тип. Например, `Animal a = new Dog(); a.Speak();` вызовет `Dog.Speak()`, потому что метод виртуальный и переопределён. Это позволяет добавлять новые типы без правки старого кода (OCP).
</details>

<details>
<summary>Задача 2 — решение</summary>

- `struct` — тип значения: копируется при присваивании, хранится обычно на стеке. Подходит для мелких, неизменяемых сущностей (Point, Money).
- `class` — ссылочный тип: переменная хранит ссылку. Подходит для остального; наследование и изменение.
</details>

<details>
<summary>Задача 3 — решение</summary>

| Признак | abstract class | interface |
|---|---|---|
| Наследование | одно | много |
| Состояние/поля | да | нет |
| Конструктор | да | нет |
| Когда | общая логика + IS-A | контракт, CAN-DO |
</details>

<details>
<summary>Задача 4 — решение</summary>

Слои: Domain (Order, IOrderRepository) → Application (OrderService с DI) → Infrastructure (EF/файл) → Presentation (API). Тесты: фейк-репозиторий. Зависимости внутрь.
</details>

<details>
<summary>Задача 5 — решение</summary>

Ошибка: выход за границы, если `numbers.Length < 10`.
Безопасно: `sum += numbers[i];` в цикле до `numbers.Length`, или `foreach`. Либо проверять длину.
</details>
