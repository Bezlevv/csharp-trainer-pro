# Модуль 23: Подготовка к собеседованию и повторение

> **Цель:** систематизировать знания, повторить ключевые темы и потренироваться в типичных вопросах.

## Зачем это нужно
После курса полезно «собрать» знания воедино и отрепетировать собеседование. Это поможет уверенно отвечать и выявить пробелы.

## Теория

### 1. Карта повторения (что спросят)

| Область | Ключевые вопросы |
|---|---|
| Базовый синтаксис | типы, var, null, строки, операторы |
| ООП | классы, инкапсуляция, наследование, полиморфизм, интерфейсы |
| Коллекции | List, Dictionary, HashSet, сложности O(...) |
| Исключения | try/catch, свои исключения, throw vs rethrow |
| LINQ | Where/Select/OrderBy, отложенное выполнение |
| Асинхронность | async/await, Task.WhenAll, CancellationToken |
| Тесты | xUnit, AAA, моки |
| SOLID | 5 принципов, примеры |
| ASP.NET Core | minimal API, DI, middleware, JWT |

### 2. Как отвечать
- Сначала — суть (1–2 фразы).
- Потом — пример.
- Затем — «почему это важно / когда использовать».

### 3. Типичные вопросы

1. В чём разница `class` и `struct`?
2. Чем `abstract class` отличается от `interface`?
3. Что такое отложенное выполнение LINQ?
4. Зачем `async/await`, а не `.Result`?
5. Что такое DI и зачем она?
6. Что такое `IDisposable` и `using`?
7. Чем `==` отличается от `.Equals()`?
8. Что такое `StringBuilder` и когда он нужен?
9. Что означает «ссылочный тип» и «тип значения»?
10. Как бы ты спроектировал небольшой сервис?

### 4. Мини-шпаргалка

```csharp
// тип значения vs ссылочный
int a = 5;       // значение, копируется
string s = "x";  // ссылка, в стеке ссылка на объект в куче

// Null-безопасность
string? maybe = null;
int len = maybe?.Length ?? 0;

// интерфейс vs абстрактный класс
interface IShape { double Area(); }
abstract class Shape { public abstract double Area(); }
```

## Типичные ошибки на собеседовании

| Ошибка | Как правильно |
|---|---|
| Учить наизусть определения | понимать и объяснять своими словами |
| Не знать сложность коллекций | запомнить O(1)/O(n) |
| Путать `abstract class` и `interface` | таблица отличий |
| Не уметь объяснить SOLID на примере | подготовь примеры |
