# Урок 34. LINQ

## Цель
Научиться красиво и коротко «спрашивать» коллекции вместо длинных циклов.

## Словарик новых слов
- **LINQ** — встроенный язык запросов к коллекциям.
- **`Where`** — «отфильтруй» (оставь подходящих).
- **`Select`** — «возьми только нужное поле» (проекция).
- **`OrderBy`** — «отсортируй».
- **`Take`** — «возьми первые N».
- **`ToList()`** — превратить результат в список.

## Теория «с нуля»

### Аналогия: вопрос к очереди
Представь список людей. Ты можешь задать вопросы:
- «Дай всех, кому ≥ 18» → `Where(p => p.Age >= 18)`.
- «Дай только их имена» → `Select(p => p.Name)`.
- «Отсортируй по имени» → `OrderBy(p => p.Name)`.
- «Возьми первых трёх» → `Take(3)`.

LINQ — это такие же «вопросы», только в коде.

### Цепочка вопросов
```csharp
List<Person> adults = people
    .Where(p => p.Age >= 18)
    .OrderBy(p => p.Name)
    .ToList();
```

Читается как предложение: «возьми людей, отфильтруй >= 18, отсортируй по имени, преврати в список».

### Где взять данные
```csharp
record Person(string Name, int Age);

List<Person> people = new()
{
    new("Иван", 30),
    new("Аня", 17),
    new("Мария", 25)
};
```

### Самые частые операторы
| Оператор | Что делает | Пример |
|---|---|---|
| `Where(...)` | фильтр | `.Where(p => p.Age >= 18)` |
| `Select(...)` | проекция | `.Select(p => p.Name)` |
| `OrderBy(...)` | сортировка | `.OrderBy(p => p.Name)` |
| `Take(n)` | первые n | `.Take(3)` |
| `Skip(n)` | пропустить n | `.Skip(2)` |
| `FirstOrDefault()` | первый или null | `.FirstOrDefault()` |
| `Count()` | количество | `.Count()` |
| `Any(...)` | есть ли хоть один | `.Any(p => p.Age > 100)` |
| `Sum(...)` | сумма | `.Sum(p => p.Age)` |

### Лямбда `p => ...`
Запись `p => p.Age` — «для каждого p — верни p.Age». Это стрелочная функция (из урока про делегаты, можно просто воспринимать как «что взять от элемента»).

### Почему LINQ удобен
- Короче и читаемее циклов.
- Операторы можно соединять цепочкой.
- Легче понять намерение: «фильтр», «сортировка».

## Примеры

**Имена взрослых по алфавиту:**
```csharp
List<string> names = people
    .Where(p => p.Age >= 18)
    .OrderBy(p => p.Name)
    .Select(p => p.Name)
    .ToList();
```

**Средний возраст:**
```csharp
double avg = people.Average(p => p.Age);
```

## Сделай сам (задачи с подсказками)

1. Из списка чисел `{ 5, 12, 7, 20 }` выбери больше 10.
   *Подсказка: `Where(n => n > 10)`.*
2. Отсортируй по убыванию.
   *Подсказка: `OrderByDescending(n => n)`.*
3. Возьми первые 2 числа.
   *Подсказка: `Take(2)`.*
4. Из людей выбери имена тех, кому ≥ 18, по алфавиту.
   *Подсказка: `Where` → `OrderBy` → `Select` → `ToList`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| Забыл `ToList()` и перебираешь несколько раз | запрос пересчитывается | материализуй `ToList()` |
| `First()` на пустом | исключение | `FirstOrDefault()` |
| `Select` в цикле вместо `SelectMany` | вложенные списки | `SelectMany` (для списков списков) |
| `Where(...).ToList()` без нужды | лишняя аллокация | оставляй ленивым при однократном переборе |

## Тест — проверь себя

**Вопрос 1.** Что делает `.Where(p => p.Age >= 18)`?
- A) Сортирует.
- B) Оставляет только тех, у кого Age ≥ 18.
- C) Удаляет всех.

✅ **Верно: B.**
Почему: Where — фильтр по условию.
Почему неверны остальные:
- A — Сортировка — это OrderBy.
- C — Фильтр не удаляет всех.

**Вопрос 2.** Что вернёт `.Select(p => p.Name)`?
- A) Объекты Person.
- B) Только имена (строки).
- C) Числа.

✅ **Верно: B.**
Почему: Select «берёт» поле Name.
Почему неверны остальные:
- A — Это, не проекция.
- C — Если только имена не числа, но здесь они строки.

**Вопрос 3.** Зачем `.ToList()` в конце цепочки?
- A) Чтобы красиво вывести.
- B) Чтобы «материализовать» результат в список (выполнить запрос).
- C) Чтобы отсортировать.

✅ **Верно: B.**
Почему: без ToList запрос «ленивый» и выполняется при переборе; ToList фиксирует результат.
Почему неверны остальные:
- A — Это не про вывод.
- C — Сортировка — это OrderBy.

**Вопрос 4.** Как найти первый элемент, или null, если никого нет?
- A) `.First()`
- B) `.FirstOrDefault()`
- C) `.Take(1)`

✅ **Верно: B.**
Почему: FirstOrDefault возвращает первый или default/null без исключения.
Почему неверны остальные:
- A — First на пустом бросит исключение.
- C — Take(1) вернёт коллекцию из одного элемента, а не сам элемент.

## Итог урока
- LINQ — «вопросы» к коллекциям: Where, Select, OrderBy, Take...
- Цепочки операторов читаются как предложение.
- `ToList()` — материализация результата.
- `FirstOrDefault()` — безопасное взятие первого.
