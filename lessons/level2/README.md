# Уровень 2 — Junior (ООП)

Уровень, где начинается настоящий «профессиональный» способ писать код — **объектно-ориентированное программирование (ООП)**.

> Что значит «ООП»? Это способ организовать код, собирая данные и действия с ними в один «контейнер» — класс. Слово «объектно-ориентированное» означает: мы мыслим объектами (вещами) реального мира.
>
> Если какое-то слово тебе незнакомо — в конце каждого урока есть **Словарик**: я объясняю каждый термин простыми словами.
