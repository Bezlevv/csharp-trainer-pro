# Урок 23. Наследование

## Цель
Понять, как сделать «семейство» классов: общее — в базовом, особенное — в наследниках.

## Словарик новых слов
- **Наследование** — механизм, при котором класс получает (наследует) члены другого класса.
- **Базовый класс** — «родитель», от которого наследуют.
- **Наследник (производный класс)** — «ребёнок», который берёт родительское и добавляет своё.
- **`base`** — ссылка на базовый класс (например, чтобы вызвать его конструктор).

## Теория «с нуля»

### Аналогия: семейство животных
Опишем «Животное»: у него есть имя и умение есть. Теперь «Собака» — это Животное + умеет лаять. «Кошка» — Животное + умеет мурчать. Общее (имя, есть) кладём в базовый класс, а особенное — в наследников.

### Базовый класс
```csharp
class Animal
{
    public string Name { get; set; }

    public void Eat()
    {
        Console.WriteLine($"{Name} ест");
    }
}
```

### Наследник
```csharp
class Dog : Animal
{
    public void Bark()
    {
        Console.WriteLine("Гав!");
    }
}
```

Символ `:` означает «наследуется от». Теперь `Dog` имеет всё от `Animal` плюс своё:
```csharp
Dog dog = new Dog();
dog.Name = "Рекс";
dog.Eat();    // из базового класса
dog.Bark();   // своё
```

### Конструкторы и `base`
Если у базового класса есть конструктор с параметрами, наследник обязан его вызвать:
```csharp
class Animal
{
    public string Name { get; }
    public Animal(string name) { Name = name; }
}

class Dog : Animal
{
    public Dog(string name) : base(name) { }   // вызываем конструктор Animal
}
```

`: base(name)` — «вызови родительский конструктор, передав ему name».

### Одиночное наследование
В C# класс может иметь **только одного** «родителя». (А вот интерфейсов — можно много, см. следующий урок.)

## Примеры

```csharp
class Shape
{
    public virtual double Area() => 0;
}

class Circle : Shape
{
    public double Radius { get; }
    public Circle(double radius) { Radius = radius; }

    public override double Area() => Math.PI * Radius * Radius;
}
```

(Про `virtual`/`override` — подробно в следующем уроке.)

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `class Dog : Animal` но без конструктора `base` | если у Animal конструктор с параметром — ошибка | добавь `: base(...)` |
| Наследование «ради переиспользования» кода | не родственная связь | лучше композиция (поле внутри) |
| `class Dog : Animal, Another` | множественное наследование классов запрещено | один базовый класс |
| Забыл `public` у членов | недоступны наследнику/извне | `public` или `protected` |

## Тест — проверь себя

**Вопрос 1.** Что означает `class Dog : Animal`?
- A) Dog содержит объект Animal.
- B) Dog наследует (получает) члены Animal.
- C) Dog и Animal — одно и то же.

✅ **Верно: B.**
Почему: `:` — знак наследования.
Почему неверны остальные:
- A — «Содержит объект» — это композиция, не наследование.
- C — Это разные классы, просто связанные.

**Вопрос 2.** Что унаследует `Dog` от `Animal`?
- A) Только методы.
- B) Все `public` (и `protected`) члены Animal.
- C) Ничего.

✅ **Верно: B.**
Почему: доступные члены базового класса становятся доступны наследнику.
Почему неверны остальные:
- A — Наследуются и поля/свойства, и методы.
- C — Наследование — это и есть передача членов.

**Вопрос 3.** Как вызвать конструктор базового класса?
- A) `base(name)`
- B) `super(name)`
- C) Никак, он вызывается сам всегда с теми же параметрами.

✅ **Верно: A.**
Почему: в C# — `base(...)`.
Почему неверны остальные:
- B — `super` — это из Java/Python, в C# так нельзя.
- C — Параметры нужно передать явно.

**Вопрос 4.** Можно ли сделать `class Dog : Animal, Machine`?
- A) Да.
- B) Нет: в C# у класса один базовый класс.
- C) Да, если Machine — абстрактный.

✅ **Верно: B.**
Почему: множественное наследование классов в C# запрещено.
Почему неверны остальные:
- A — Нельзя.
- C — Абстрактность не меняет количество базовых классов.

## Итог урока
- **Наследование** — класс получает члены другого класса (`:`).
- Базовый класс — общее; наследник — добавляет своё.
- Конструктор базового класса вызывается через `base(...)`.
- Базовый класс — один.
