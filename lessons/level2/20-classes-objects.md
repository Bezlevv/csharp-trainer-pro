# Урок 20. Классы и объекты

## Цель
Понять главную идею ООП — «класс» и «объект» — и создать свой первый класс.

## Словарик новых слов
- **Класс** — «чертёж» или «форма». Описывает, какие данные и действия будут у создаваемых «изделий». Сам по себе он ещё не вещь.
- **Объект** — конкретное «изделие», созданное по чертёжу (классу). Ему можно дать имя и использовать.
- **Поле** — переменная внутри класса, хранящая данные объекта.
- **Метод** — действие, которое объект умеет выполнять.

## Теория «с нуля»

### Аналогия: чертёж и автомобиль
Представь завод:
- **Чертёж** «Автомобиль» — это класс. На нём нарисовано: есть руль (поле), есть колёса (поле), есть действие «завестись» (метод). Но чертёж сам по себе не ездит.
- **Автомобиль** на парковке — это объект. Его сделали по чертёжу. Таких машин может быть много, но все они — по одному чертёжу.

### Класс в коде
```csharp
class Car
{
    // поля — данные объекта
    public string Color;
    public int Speed;

    // метод — действие объекта
    public void Honk()
    {
        Console.WriteLine("Бип!");
    }
}
```

### Создание объекта
Объект создаётся словом `new`:
```csharp
Car myCar = new Car();
myCar.Color = "Красный";   // заполняем поле
myCar.Speed = 60;
myCar.Honk();              // вызываем метод — "Бип!"
```

### Класс ≠ объект — главное различие
```csharp
// Car — это "чертёж" (тип). myCar — конкретный объект.
Car myCar = new Car();
```

Если сказать «создай класс» — мы описываем чертёж. Если «создай объект» — делаем конкретное изделие.

## Сделай сам (задачи с подсказками)

1. Создай класс `Dog` с полем `string Name` и методом `Bark()` (выводит «Гав!»).
   *Подсказка: `class Dog { public string Name; public void Bark() { Console.WriteLine("Гав!"); } }`*
2. Создай два объекта `Dog` с разными именами и вызови у обоих `Bark()`.
   *Подсказка: `Dog d1 = new Dog(); d1.Name = "Рекс";` и т.д.*
3. Создай класс `Person` с полями `Name` и `Age` и методом `Introduce()` (выводит «Привет, я ...»).
   *Подсказка: внутри метода используй `Console.WriteLine($"Привет, я {Name}");`*
4. Создай класс `Rectangle` с полями `Width`, `Height` и методом `Area()`, возвращающим площадь.
   *Подсказка: `public double Area() { return Width * Height; }`*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `Car myCar;` без `new` | объект не создан (myCar = null) | `= new Car();` |
| `new Car()` без переменной | объект создан, но мы его не можем использовать | сохрани в переменную |
| Обращение к полю `myCar.Color` до создания | ошибка (null) | сначала создай объект |
| Имя метода `Bark()` с прописной | методы — с большой буквы | `Bark()`, не `bark()` |

## Тест — проверь себя

**Вопрос 1.** Что такое класс?
- A) Конкретная вещь в памяти.
- B) «Чертёж», описывающий данные и действия.
- C) Переменная.

✅ **Верно: B.**
Почему: класс — описание (тип), а не конкретная вещь.
Почему неверны остальные:
- A — Конкретная вещь — это объект.
- C — Переменная хранит значение; класс — это тип/шаблон.

**Вопрос 2.** Что такое объект?
- A) Чертёж.
- B) Конкретное «изделие», созданное по классу.
- C) Имя класса.

✅ **Верно: B.**
Почему: объект — реальный экземпляр, созданный через `new`.
Почему неверны остальные:
- A — Чертёж — это класс.
- C — Имя класса — не объект.

**Вопрос 3.** Как создать объект класса `Car`?
- A) `Car myCar = new Car();`
- B) `Car myCar;`
- C) `new Car myCar;`

✅ **Верно: A.**
Почему: `new Car()` создаёт объект, и мы сохраняем его в переменную.
Почему неверны остальные:
- B — Объявлена только переменная, объект не создан (будет `null`).
- C — Неверный порядок слов; `new` идёт перед типом.

**Вопрос 4.** Что выведет код?
```csharp
class Cat { public void Meow() { Console.WriteLine("Мяу!"); } }
Cat c = new Cat();
c.Meow();
```
- A) Ничего.
- B) `Мяу!`
- C) Ошибку.

✅ **Верно: B.**
Почему: создали объект `c` и вызвали его метод `Meow()`, который выводит «Мяу!».
Почему неверны остальные:
- A — Метод выводит текст.
- C — Ошибки нет: класс и метод описаны верно.

## Итог урока
- **Класс** — чертёж (тип). **Объект** — изделие по чертёжу.
- Объект создаётся через `new`.
- Поля — данные; методы — действия объекта.
- Чтобы использовать объект, сохрани его в переменную.
