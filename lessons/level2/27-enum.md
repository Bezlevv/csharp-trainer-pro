# Урок 27. Перечисления enum

## Цель
Научиться задавать «список заранее известных вариантов» и использовать его вместо магических чисел и строк.

## Словарик новых слов
- **Перечисление (enum)** — тип, который перечисляет набор именованных вариантов.
- **Магическое число** — число в коде без пояснений (например, `3` — «а что значит 3?»).
- **Строка-статус** — статус, хранимый как текст (легко ошибиться в регистре/опечатке).

## Теория «с нуля»

### Аналогия: дни недели
В неделе заранее заданы 7 дней. «Пятница» — это определённый вариант, а не произвольный текст. Если бы мы записывали день просто строкой, легко было бы написать «пятнца» с опечаткой. Перечисление исключает такие ошибки.

### Объявление enum
```csharp
enum OrderStatus
{
    New,
    Paid,
    Shipped,
    Delivered
}
```

Теперь `OrderStatus` — тип, у которого возможны только эти значения.

### Использование
```csharp
OrderStatus status = OrderStatus.Paid;

if (status == OrderStatus.Paid)
{
    Console.WriteLine("Заказ оплачен");
}
```

### Почему это лучше «магических чисел»
Плохо:
```csharp
if (orderStatus == 2) { ... }   // что такое 2?
```
Хорошо:
```csharp
if (orderStatus == OrderStatus.Paid) { ... }
```
Имя `Paid` объясняет смысл, и нельзя перепутать с другой веткой.

### enum в switch
```csharp
string message = status switch
{
    OrderStatus.New => "Новый",
    OrderStatus.Paid => "Оплачен",
    OrderStatus.Shipped => "Отправлен",
    OrderStatus.Delivered => "Доставлен",
    _ => "Неизвестно"
};
```

### Парсинг
Превращение строки в enum:
```csharp
if (Enum.TryParse("Paid", out OrderStatus s))
{
    Console.WriteLine(s);   // Paid
}
```

## Примеры

```csharp
enum Priority { Low, Medium, High }

Priority p = Priority.High;

if (p == Priority.High) Console.WriteLine("Срочно!");
```

## Сделай сам (задачи с подсказками)

1. Создай `enum Weekday { Monday, Tuesday, ... }` и выведи, что `Weekday.Friday` — это валидное значение.
   *Подсказка: `enum Weekday { Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday }`*
2. Создай `enum TaskStatus { Todo, InProgress, Done }` и используй его в `if`.
   *Подсказка: `if (status == TaskStatus.Done)`.*
3. Создай `enum Priority { Low, Medium, High }` и switch-выражение, возвращающее строку.
   *Подсказка: `Priority.High => "Высокий"`.*
4. Перепиши код, где статус был строкой "done"/"DONE", на enum.
   *Подсказка: теперь сравнение безопасно: `status == TaskStatus.Done`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| Сравнение `status == "done"` для enum | типы не совпадают (enum vs string) | `status == TaskStatus.Done` |
| `int` вместо enum | магические числа | используй enum |
| Забыл `_` в switch-выражении | может быть не покрыто | добавляй `_ => ...` |
| Имя enum с маленькой буквы | типы — с большой | `OrderStatus`, не `orderStatus` |

## Тест — проверь себя

**Вопрос 1.** Что такое `enum`?
- A) Структура с методами.
- B) Тип с заранее заданным набором именованных вариантов.
- C) Переменная для чисел.

✅ **Верно: B.**
Почему: enum перечисляет допустимые варианты.
Почему неверны остальные:
- A — Это не структура с логикой.
- C — Это не про «любые числа».

**Вопрос 2.** Зачем использовать enum вместо строки-статуса?
- A) Чтобы код был длиннее.
- B) Чтобы исключить опечатки и перепутывание вариантов.
- C) Чтобы быстрее работало.

✅ **Верно: B.**
Почему: набор вариантов фиксирован, нельзя случайно написать «doneed».
Почему неверны остальные:
- A — Это не про длину.
- C — Главное — надёжность, а не скорость.

**Вопрос 3.** Как сравнить, что `status` равен `Paid`?
- A) `status == "Paid"`
- B) `status == OrderStatus.Paid`
- C) `status.Paid`

✅ **Верно: B.**
Почему: сравниваем значение enum с элементом типа.
Почему неверны остальные:
- A — Строку нельзя сравнить с enum напрямую (типы разные).
- C — Такой синтаксис не существует.

**Вопрос 4.** Что делает `Enum.TryParse("Paid", out OrderStatus s)`?
- A) Выводит «Paid».
- B) Пытается превратить строку в значение enum.
- C) Создаёт новый enum.

✅ **Верно: B.**
Почему: это безопасный разбор строки в enum.
Почему неверны остальные:
- A — Это не вывод.
- C — Enum не «создаётся» так.

## Итог урока
- `enum` — набор именованных вариантов.
- Заменяет «магические числа» и строки-статусы.
- Сравнение — через `==` с элементом enum.
- `Enum.TryParse` — безопасный разбор строки.
