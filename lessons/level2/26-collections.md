# Урок 26. Коллекции

## Цель
Познакомиться с коллекциями — «умными контейнерами» для множества значений: списком, словарём и множеством.

## Словарик новых слов
- **Коллекция** — контейнер, который хранит много значений и умеет с ними работать (добавлять, искать, удалять).
- **`List<T>`** — динамический список: «вереница» элементов, размер может расти.
- **`Dictionary<TKey,TValue>`** — словарь: пары «ключ → значение», мгновенный поиск по ключу.
- **`HashSet<T>`** — множество уникальных элементов, быстрая проверка «есть ли».
- **Обобщение (generic) `<T>`** — «тип-заполнитель»: подставляем реальный тип, например `List<int>`.

## Теория «с нуля»

### Почему не хватает массива
Массив — фиксированного размера. А часто нужно добавлять/убирать элементы. Для этого есть коллекции.

### List<T> — список
```csharp
List<string> names = new List<string>();
names.Add("Иван");
names.Add("Мария");
Console.WriteLine(names[0]);    // "Иван"
names.Remove("Иван");
Console.WriteLine(names.Count);  // 1
```

- `Add` — добавить, `Remove` — удалить, `Count` — количество.
- Доступ по индексу, как у массива: `names[0]`.
- Удобный способ создать с данными: `List<int> nums = new List<int> { 1, 2, 3 };`

### Словарь Dictionary — «телефонная книга»
```csharp
Dictionary<string, int> ages = new Dictionary<string, int>();
ages["Иван"] = 30;
ages["Мария"] = 28;

Console.WriteLine(ages["Иван"]);           // 30
if (ages.ContainsKey("Пётр"))
{
    Console.WriteLine(ages["Пётр"]);
}
else
{
    Console.WriteLine("Такого ключа нет");
}
```

Словарь хранит пары. По **ключу** ищет очень быстро. Ключи уникальны.

### Множество HashSet — «список с отсутствием повторов»
```csharp
HashSet<string> tags = new HashSet<string>();
tags.Add("csharp");
tags.Add("csharp");   // дубликат игнорируется
Console.WriteLine(tags.Count);              // 1
Console.WriteLine(tags.Contains("csharp")); // True
```

`HashSet` гарантирует уникальность и быстро отвечает «есть ли элемент».

### Перебор foreach
Любую коллекцию можно перебрать:
```csharp
foreach (string name in names)
{
    Console.WriteLine(name);
}
```

## Примеры

```csharp
List<int> numbers = new List<int> { 4, 1, 3 };
numbers.Sort();                     // 1, 3, 4
int total = 0;
foreach (int n in numbers) total += n;
Console.WriteLine(total);           // 8
```

## Сделай сам (задачи с подсказками)

1. `List<string>`: добавь три имени, выведи количество и второе имя.
   *Подсказка: `names.Add("...")` и `names[1]`.*
2. Словарь-«телефонная книга»: добавь пары «имя → номер», найди номер по имени.
   *Подсказка: `dict[name]` и `ContainsKey`.*
3. Подсчитай частоту слов в строке через `Dictionary<string,int>`.
   *Подсказка: `dict[word] = dict.GetValueOrDefault(word) + 1;`*
4. `HashSet<int>`: добавь числа и выведи, есть ли в нём 5.
   *Подсказка: `Contains(5)`.*
5. Перебери словарь через foreach и выведи ключи и значения.
   *Подсказка: `foreach (var pair in dict) Console.WriteLine($"{pair.Key}: {pair.Value}");`*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `dict["нет_такого"]` без проверки | ошибка KeyNotFoundException | используй `ContainsKey` или `TryGetValue` |
| Изменение коллекции во время foreach | ошибка | собери изменения отдельно, примени потом |
| Дубликаты в HashSet и ожидание двух | их будет один | HashSet — для уникальности |
| `List<T>` там, где нужен быстрый поиск | ищет долго (O(n)) | для поиска — Dictionary/HashSet |

## Тест — проверь себя

**Вопрос 1.** Что подходит для быстрого поиска по ключу?
- A) `List<T>`
- B) `Dictionary<TKey,TValue>`
- C) Массив

✅ **Верно: B.**
Почему: словарь ищет по ключу очень быстро.
Почему неверны остальные:
- A, C — Список/массив ищут перебором (медленнее).

**Вопрос 2.** Что будет, если в `HashSet<int>` добавить одно и то же число дважды?
- A) Оно попадёт дважды.
- B) Останется одно вхождение (дубликат отброшен).
- C) Ошибка.

✅ **Верно: B.**
Почему: `HashSet` хранит только уникальные элементы.
Почему неверны остальные:
- A — Известных повторов не будет.
- C — Ошибки нет, просто дубликат игнорируется.

**Вопрос 3.** Чем `List<string>` отличается от массива `string[]`?
- A) Ничем.
- B) Список умеет расти (Add/Remove); массив фиксирован.
- C) Массив умеет расти.

✅ **Верно: B.**
Почему: `List` динамический, массив — фиксированный.
Почему неверны остальные:
- A — Разница есть.
- C — Наоборот.

**Вопрос 4.** Что выведет код?
```csharp
List<int> list = new List<int> { 1, 2, 3 };
list.Add(4);
Console.WriteLine(list.Count);
```
- A) 3
- B) 4
- C) 7

✅ **Верно: B.**
Почему: было 3 элемента, добавили 1 → стало 4.
Почему неверны остальные:
- A — 3 — это до добавления.
- C — 7 — это сумма значений, а не количество.

## Итог урока
- `List<T>` — динамический список с Add/Remove.
- `Dictionary<TKey,TValue>` — пары «ключ→значение», быстрый поиск.
- `HashSet<T>` — уникальные элементы.
- `foreach` перебирает любую коллекцию.
