# Урок 22. Конструкторы

## Цель
Понять, как объект «рождается» и как задать его начальное состояние сразу при создании.

## Словарик новых слов
- **Конструктор** — специальный метод, который вызывается автоматически при создании объекта (`new`). Он «настраивает» объект с самого начала.
- **Параметр** — входное значение метода.
- **Инициализация** — задание начальных значений.

## Теория «с нуля»

### Аналогия: регистрация новорождённого
Когда рождается человек, его сразу регистрируют: дают имя, записывают дату рождения. Так и объект: при создании (через `new`) вызывается **конструктор**, который может сразу задать его данные.

### Конструктор по умолчанию
Если ты ничего не пишешь, C# создаёт пустой конструктор: поля остаются со значениями «по умолчанию» (у чисел — 0, у строк — null).
```csharp
class Person { public string Name { get; set; } }

Person p = new Person();   // вызвался конструктор по умолчанию
```

### Свой конструктор
```csharp
class Person
{
    public string Name { get; }

    public Person(string name)   // конструктор с параметром
    {
        Name = name;
    }
}
```

Теперь при создании **обязательно** передаём имя:
```csharp
Person p = new Person("Иван");   // сразу имя задано
```

Имя конструктора совпадает с именем класса, и у него нет типа возврата.

### Почему это полезно
1. Объект не может появиться «наполовину настроенным».
2. Нельзя забыть важные данные — они передаются сразу.
3. Можно поставить проверки в конструкторе.

### Проверка в конструкторе
```csharp
public Person(string name)
{
    if (string.IsNullOrWhiteSpace(name))
        throw new ArgumentException("Имя не может быть пустым");
    Name = name;
}
```

### Несколько конструкторов
Можно сделать несколько конструкторов (с разными наборами параметров):
```csharp
public Person()                        { Name = "Без имени"; }
public Person(string name)             { Name = name; }
```

## Примеры

```csharp
class Rectangle
{
    public double Width { get; }
    public double Height { get; }

    public Rectangle(double width, double height)
    {
        Width = width;
        Height = height;
    }

    public double Area() => Width * Height;
}
```

```csharp
Rectangle r = new Rectangle(4, 5);
Console.WriteLine(r.Area());   // 20
```

   *Подсказка: `public Car(string color) { Color = color; }`*

   *Подсказка: проверка `string.IsNullOrWhiteSpace(name)`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `Person(string name)` без `public` | не виден снаружи | `public` |
| Конструктор с типом возврата (`void Person(...)`) | у конструктора нет типа возврата | просто `Person(...)` |
| `new Person()` при единственном конструкторе с параметром | такого конструктора нет | передай параметр: `new Person("И")` |
| Забыл `{ }` у конструктора | пустой код | добавь тело |

## Тест — проверь себя

**Вопрос 1.** Когда вызывается конструктор?
- A) Когда вызываешь метод `Run()`.
- B) Автоматически при создании объекта (`new`).
- C) При выходе из программы.

✅ **Верно: B.**
Почему: конструктор срабатывает в момент `new`.
Почему неверны остальные:
- A — `Run()` — обычный метод.
- C — При выходе вызывается деструктор/очистка, не конструктор.

**Вопрос 2.** У конструктора:
- A) Есть тип возврата `void`.
- B) Нет типа возврата.
- C) Обязательно есть `return`.

✅ **Верно: B.**
Почему: конструктор не возвращает значение, поэтому типа возврата нет.
Почему неверны остальные:
- A — `void` в конструкторе писать нельзя.
- C — `return` там не нужен.

**Вопрос 3.** Что произойдёт при `Person p = new Person();`, если есть только конструктор `Person(string name)`?
- A) Создастся объект с пустым именем.
- B) Ошибка компиляции: такого конструктора без параметров нет.
- C) Создастся объект с именем null.

✅ **Верно: B.**
Почему: раз объявлен конструктор с параметром, «пустого» конструктора больше нет — вызов без аргументов не сработает.
Почему неверны остальные:
- A, C — Без cствующего конструктора объект не создастся вовсе.

**Вопрос 4.** Зачем задавать данные через конструктор?
- A) Чтобы объект сразу был корректно настроен, и нельзя было «забыть» важное.
- B) Чтобы программа работала медленнее.
- C) Чтобы поля были скрыты.

✅ **Верно: A.**
Почему: конструктор гарантирует начальное состояние.
Почему неверны остальные:
- B — Это не про скорость.
- C — Скрытие полей — это инкапсуляция (прошлый урок), не цель конструктора.

## Итог урока
- **Конструктор** — автоматический метод при `new`, имя = имя класса, без типа возврата.
- Позволяет сразу задать данные и проверить их.
- Если объявил конструктор — «пустого» больше нет.
