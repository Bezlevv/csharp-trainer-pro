# Урок 01. Переменные и типы

## Цель
Научиться хранить значения в переменных и выбирать правильный тип.

## Теория «как для ребёнка»

### Что такое переменная?
**Переменная — это коробочка с наклейкой.** Ты пишешь имя на коробочке (например, `age`), кладёшь внутрь значение (`25`), а потом обращаешься к коробочке по имени.

```csharp
int age = 25;      // коробочка "age", внутри число 25
string name = "Иван"; // коробочка "name", внутри текст "Иван"
```

Читается так: **«коробочка age будет хранить целое число 25»**.

### Что такое тип?
**Тип — размер и «содержимое» коробочки.** Нельзя положить текст в коробочку для чисел — она для этого не предназначена, и компилятор скажет об ошибке.

Главные типы для старта:

| Тип | Что хранит | Пример | Аналогия |
|---|---|---|---|
| `int` | целые числа | `25`, `-7`, `0` | коробочка для «штук» |
| `double` | дробные числа | `3.14`, `0.5` | коробочка для «кусочков» |
| `string` | текст | `"Привет"` | коробочка для слов |
| `bool` | да/нет | `true`, `false` | коробочка с выключателем |

### Как вывести содержимое коробочки?
```csharp
int age = 25;
Console.WriteLine(age);   // выведет 25
```

### `var` — «угадай сам»
Можно написать `var age = 25;` — компилятор сам поймёт, что это `int`. Но для начала лучше писать тип явно: так понятнее.

## Примеры

```csharp
int appleCount = 3;
double price = 49.90;
string greeting = "Добрый день!";
bool isLearning = true;

Console.WriteLine(appleCount);
Console.WriteLine(price);
Console.WriteLine(greeting);
Console.WriteLine(isLearning);
```

## Сделай сам (задачи с подсказками)

1. Создай переменные: возраст (int), имя (string), рост в метрах (double), учится ли (bool). Выведи все.
   *Подсказка: четыре переменные, четыре `Console.WriteLine(...)`.*
2. Создай `int year = 2026;` и выведи его.
   *Подсказка: переменная уже есть — осталось вывести.*
3. Заведи `string city = "Москва";` и выведи «Я живу в Москве».
   *Подсказка: `Console.WriteLine("Я живу в " + city);` — «+» склеивает строки.*
4. Попробуй положить `true` в `int` — что скажет компилятор? Запиши вывод ошибки.
   *Подсказка: это будет ошибка типа — текст не помещается в коробочку для чисел.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `int age = "Иван";` | текст в коробочке для чисел | `string age = "Иван";` |
| `Console.WriteLine(Age);` (большая A) | имя переменной чувствительно к регистру | `Console.WriteLine(age);` |
| Забыл объявить: `Console.WriteLine(age);` без `int age = ...` | коробочки ещё нет | сначала создать переменную |
| `string name = Иван;` без кавычек | текст обязан быть в кавычках | `string name = "Иван";` |

## Тест — проверь себя

**Вопрос 1.** Какой тип у значения `3.14`?
- A) `int`
- B) `double`
- C) `string`

✅ **Верно: B.**
Почему: 3.14 — дробное число → нужна коробочка `double`.
Почему неверны остальные:
- A — `int` хранит только целые (без запятой).
- C — `string` — это текст в кавычках, а не число.

**Вопрос 2.** Что хранит переменная `bool isStudent = true;`?
- A) Число.
- B) Текст.
- C) Логическое значение «да» (true).

✅ **Верно: C.**
Почему: `bool` — только `true` или `false`, словно выключатель.
Почему неверны остальные:
- A — Числа — это `int`/`double`.
- B — Текст — это `string`.

**Вопрос 3.** Почему `int age = "25";` — ошибка?
- A) Потому что 25 слишком большое число.
- B) Потому что `"25"` — это текст, а `int` ожидает число.
- C) Потому что имя `age` запрещено.

✅ **Верно: B.**
Почему: кавычки делают `"25"` текстом; положить текст в коробочку для чисел нельзя.
Почему неверны остальные:
- A — 25 вполне помещается в `int`.
- C — `age` — допустимое имя.

**Вопрос 4.** Что выведет код?
```csharp
int x = 5;
Console.WriteLine(x);
```
- A) `x`
- B) `5`
- C) Ошибку

✅ **Верно: B.**
Почему: `Console.WriteLine(x)` выводит *значение* из коробочки (5), а не её имя.
Почему неверны остальные:
- A — Имя переменной на экран не выводится.
- C — Ошибки нет: переменная объявлена и заполнена.

## Итог урока
- Переменная = коробочка с наклейкой-именем.
- Тип определяет, что можно положить внутрь.
- `Console.WriteLine(имя)` выводит значение.
- Компилятор строг: не клади текст в коробочку для чисел.
