## Как заниматься

1. Читай теорию. Непонятно — вернись к аналогии «во дворе».
2. Набирай примеры руками (не копируй).
3. Решай задачи под «Сделай сам». Подсказка — внутри.
4. Смотри «Разбор ошибок» — это то, что чаще всего ломается у новичков.
5. В конце — пройди тест. Разбор каждого ответа объяснит, почему он верный или нет.

> Совет дня: если застрял — прочитай сообщение об ошибке дословно. Компилятор — переводчик с языка «твой код» на язык «человеческий».
