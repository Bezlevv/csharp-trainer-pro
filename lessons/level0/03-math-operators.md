# Урок 03. Арифметика и операторы

## Цель
Научиться выполнять вычисления и понимать «подводные камни» целых чисел.

## Теория «как для ребёнка»

### Компьютер умеет считать
Как и калькулятор, C# знает знаки:

| Знак | Что делает | Пример |
|---|---|---|
| `+` | сложение | `5 + 3` → `8` |
| `-` | вычитание | `5 - 3` → `2` |
| `*` | умножение | `5 * 3` → `15` |
| `/` | деление | `6 / 3` → `2` |
| `%` | остаток от деления | `7 % 3` → `1` |

### Главная ловушка: деление целых чисел
Если **оба числа целые** (`int`), то деление даёт **целое** число, отбрасывая дробную часть:

```csharp
Console.WriteLine(7 / 2);   // 3, а НЕ 3.5!
Console.WriteLine(7.0 / 2); // 3.5 — если хоть одно число дробное
```

Почему? Компьютер спрашивает: «7 целых кусочков делим на 2 — сколько целых кусочков у каждого? 3, и один остаётся». Остаток можно узнать через `%`:
```csharp
Console.WriteLine(7 % 2);   // 1 (остаток)
```

### Остаток `%` — волшебная палочка
`%` выдаёт остаток от деления. Это удобно, чтобы проверять «делится ли нацело»:
- `10 % 2 == 0` — правда (чётное).
- `10 % 3` → `1`.

### Порядок действий
Как в математике: сначала `( )`, потом `*` и `/`, потом `+` и `-`.
```csharp
int result = (2 + 3) * 4;   // 20
```

## Примеры

```csharp
int a = 10;
int b = 3;

Console.WriteLine(a + b);   // 13
Console.WriteLine(a - b);   // 7
Console.WriteLine(a * b);   // 30
Console.WriteLine(a / b);   // 3 (целые!)
Console.WriteLine(a % b);   // 1 (остаток)
```

## Сделай сам (задачи с подсказками)

1. Вычисли площадь прямоугольника: ширина 5, высота 8. Выведи.
   *Подсказка: `int s = 5 * 8;`*
2. Вычисли среднее трёх чисел: 10, 20, 30.
   *Подсказка: сумма `(10 + 20 + 30)` и `/ 3`; но среднее бывает дробным — используй `double`.*
3. Проверь, чётное ли число 18 (выведи остаток от деления на 2).
   *Подсказка: `18 % 2` → 0 — значит чётное.*
4. Калькулятор: сложи два числа, введённых пользователем.
   *Подсказка: `int.Parse(Console.ReadLine())` для каждого числа.*
5. Сколько полных недель в 100 днях и сколько дней останется?
   *Подсказка: недели = `100 / 7`, остаток = `100 % 7`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `7 / 2` ожидаешь `3.5` | целые делятся нацело | сделай хоть одно число дробным: `7.0 / 2` |
| `5 * 3` без скобок и переменной | результат потерян | сохрани в переменную: `int p = 5 * 3;` |
| `10 = x` | слева можно только имя переменной | `x = 10;` |
| Делишь на ноль: `x / 0` | ошибка выполнения | проверяй делитель перед делением |

## Тест — проверь себя

**Вопрос 1.** Что выведет `Console.WriteLine(9 / 2);`?
- A) `4.5`
- B) `4`
- C) `1`

✅ **Верно: B.**
Почему: оба числа целые → деление даёт целое, дробная часть отбрасывается (9 / 2 = 4, остаток 1).
Почему неверны остальные:
- A — `4.5` получилось бы только при дробном операнде (например, `9.0 / 2`).
- C — `1` — это остаток, его даёт `%`, а не `/`.

**Вопрос 2.** Что вернёт `17 % 5`?
- A) `3`
- B) `2`
- C) `3.4`

✅ **Верно: B.**
Почему: 17 ÷ 5 = 3, остаток 2 (5×3=15, 17−15=2).
Почему неверны остальные:
- A — 3 — это целая часть от деления, а не остаток.
- C — 3.4 — обычное деление, а `%` возвращает только остаток.

**Вопрос 3.** Чем `10 % 2` полезно?
- A) Оно показывает 10-ю цифру числа.
- B) Оно показывает, чётное ли число (0 — да, 1 — нет).
- C) Оно умножает на 2.

✅ **Верно: B.**
Почему: остаток от деления на 2 равен 0 у чётных и 1 у нечётных.
Почему неверны остальные:
- A — `%` не связан с цифрами.
- C — Умножение — это `*`, а не `%`.

**Вопрос 4.** В каком порядке посчитает `2 + 3 * 4`?
- A) Слева направо: (2+3)*4 = 20.
- B) Сначала умножение: 2 + (3*4) = 14.
- C) Ошибка.

✅ **Верно: B.**
Почему: `*` имеет приоритет над `+`, как в математике.
Почему неверны остальные:
- A — 20 получится только со скобками: `(2 + 3) * 4`.
- C — Ошибки нет, порядок чётко определён.

## Итог урока
- Знаки: `+ - * / %`.
- Деление целых даёт целое (отбрасывает дробь).
- `%` — остаток, нужен для проверок «делится ли нацело».
- Скобки управляют порядком действий.
