# Урок 04. Первая программа целиком

## Цель
Собрать всё изученное в одну работающую программу и запустить её.

## Теория «как для ребёнка»

### Программа — это рецепт из многих шагов
В прошлых уроках мы учили отдельные «кубики»:
- `Console.WriteLine(...)` — показать текст;
- `Console.ReadLine()` — спросить пользователя;
- переменные — «коробочки»;
- `int.Parse(...)` — превратить текст в число.

Теперь соберём их вместе. Один рецепт = несколько шагов подряд.

### Собираем анкету

```csharp
// Шаг 1: спросить имя
Console.Write("Как тебя зовут? ");
string name = Console.ReadLine();

// Шаг 2: спросить возраст
Console.Write("Сколько тебе лет? ");
int age = int.Parse(Console.ReadLine());

// Шаг 3: вывести результат
Console.WriteLine($"Привет, {name}! Тебе {age} лет.");
```

Разбор:
- `Console.Write` — вопрос без переноса строки (ответ окажется рядом).
- `Console.ReadLine()` — ждёт ввод.
- `int.Parse(...)` — превращает введённый текст в число.
- `$"..."` — интерполяция: подставляет `name` и `age`.

### Как запустить
1. Создай проект: `dotnet new console -n MyFirstApp`
2. Вставь код в `Program.cs`.
3. Запусти: `dotnet run`

## Примеры

**Калькулятор «в одно действие»:**
```csharp
Console.Write("Первое число: ");
int a = int.Parse(Console.ReadLine());

Console.Write("Второе число: ");
int b = int.Parse(Console.ReadLine());

Console.WriteLine($"Сумма: {a + b}");
```

**Проверка чётности:**
```csharp
Console.Write("Введи число: ");
int n = int.Parse(Console.ReadLine());

int remainder = n % 2;
Console.WriteLine($"Остаток от деления на 2: {remainder}");
```

## Сделай сам (задачи с подсказками)

1. **Анкета** — спроси имя, город, возраст; выведи: «Иван из Москвы, 25 лет».
   *Подсказка: три переменные, одна интерполяция с `{ }` для каждой.*
2. **Площадь прямоугольника** — спроси ширину и высоту, выведи площадь.
   *Подсказка: `double s = a * b;` — используй `double`, чтобы не терять дробь.*
3. **Конвертер минут** — спроси число минут; выведи, сколько это часов и остаток минут.
   *Подсказка: часы = `m / 60`, минуты = `m % 60`.*
4. **Зарплата** — спроси ставку за час и число часов; выведи итог.
   *Подсказка: `double total = rate * hours;`*
5. **Температура** — спроси градусы Цельсия, переведи в Фаренгейты (F = C × 9/5 + 32).
   *Подсказка: `double f = c * 9 / 5 + 32;` — но осторожно с целыми: используй `double`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `int age = Console.ReadLine();` | `ReadLine` даёт строку, а `int` ждёт число | `int age = int.Parse(Console.ReadLine());` |
| Забыл `Console.Write` и сразу `ReadLine` | пользователь не поймёт, что вводить | всегда сначала выведи вопрос-подсказку |
| `9 / 5` в формуле температур | целые дадут 1, а не 1.8 | используй `double` (`c * 9.0 / 5`) |
| Все шаги в одной строке | нечитаемо | по одному шагу на строку, добавляй комментарии `//` |

## Тест — проверь себя

**Вопрос 1.** Что выведет программа?
```csharp
string name = "Том";
int age = 30;
Console.WriteLine($"{name} — {age} лет");
```
- A) `Том — 30 лет`
- B) `name — age лет`
- C) `Том — возраст лет`

✅ **Верно: A.**
Почему: интерполяция `$` подставляет значения переменных.
Почему неверны остальные:
- B — Имена переменных не выводятся; подставляются их значения.
- C — `age` — это число 30, а не слово «возраст».

**Вопрос 2.** Зачем `int.Parse(Console.ReadLine())`?
- A) Чтобы вывести число на экран.
- B) Чтобы превратить введённый текст в число.
- C) Чтобы остановить программу.

✅ **Верно: B.**
Почему: `ReadLine` возвращает строку; `int.Parse` превращает её в число для вычислений.
Почему неверны остальные:
- A — Вывод делает `Console.WriteLine`.
- C — Остановка программы — это не задача `Parse`.

**Вопрос 3.** Что будет, если при `int.Parse(Console.ReadLine())` пользователь введёт «пять»?
- A) Программа превратит «пять» в число 5.
- B) Программа упадёт с ошибкой (не сможет превратить текст в число).
- C) Программа выведет «пять».

✅ **Верно: B.**
Почему: `int.Parse` понимает только цифры (например, "5"). «пять» — текст, он не превратится в число, и выскочит ошибка.
Почему неверны остальные:
- A — C# не понимает русские названия чисел «из коробки».
- C — Вывода не будет: раньше произойдёт ошибка.

**Вопрос 4.** Какой порядок шагов правильный?
- A) Сначала вычислить, потом спросить данные.
- B) Сначала спросить данные, потом обработать и вывести результат.
- C) Порядок не важен.

✅ **Верно: B.**
Почему: нельзя суммировать числа, которых ещё нет; сначала получаем данные, потом считаем.
Почему неверны остальные:
- A — Без данных считать нечего.
- C — Порядок критичен.
