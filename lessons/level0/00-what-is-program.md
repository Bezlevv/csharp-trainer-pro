# Урок 00. Что такое программа и компьютер

## Цель
Понять, что такое программа, чем «язык» отличается от «платформы», и сделать первый запуск кода.

## Теория «как для ребёнка»

### Что такое компьютер?
Компьютер — **очень послушный, но глупый помощник**. Он умеет делать ровно то, что ему сказали, и не умеет «догадываться». Если ты напишешь «сделай вкусный обед» — он не поймёт: слишком расплывчато. А если дашь точный рецепт — выполнит без ошибок, но и без выдумки.

### Что такое программа?
**Программа — это рецепт.** Как рецепт торта:
```
1. Возьми 3 яйца.
2. Добавь 200 г муки.
3. Перемешай.
4. Испеки при 180° 40 минут.
```
Код на C# — такой же рецепт, только для компьютера. Каждая строка — один понятный шаг.

### Чем «язык C#» отличается от «платформы .NET»?
- **C#** — язык, на котором ты пишешь рецепт (слова и правила).
- **.NET** — «кухня»: печь, плита, посуда. Она превращает твой рецепт в готовое блюдо (работающую программу).

Без C# нечего готовить, без .NET негде готовить. Нужны оба.

### Из чего состоит первая программа?

```csharp
Console.WriteLine("Привет, мир!");
```

Разбор по молекулам:
- `Console` — «телефон» для общения с компьютером.
- `WriteLine` — «напиши и перейди на новую строку».
- `("Привет, мир!")` — что именно написать (текст в кавычках).
- `;` — **точка в конце предложения**. Говорит: «шаг закончен».

## Примеры

```csharp
Console.WriteLine("Привет, мир!");
Console.WriteLine("Я учу C#");
```

Что выведется?
```
Привет, мир!
Я учу C#
```
Каждая команда — на своей строке.

## Сделай сам (задачи с подсказками)

1. Выведи надпись «Я стану программистом».
   *Подсказка: `Console.WriteLine("...");` — только свой текст.*
2. Выведи две строки: «Первый шаг» и «Второй шаг».
   *Подсказка: две команды `WriteLine` одна за другой.*
3. Измени «Привет, мир!» на своё имя.
   *Подсказка: внутри кавычек можно писать что угодно.*
4. Напиши три строчки о себе (любимый цвет, еда, город).
   *Подсказка: три команды `WriteLine`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `Console.WriteLine("Привет")` без `;` | «предложение не закончено» | добавить `;` |
| `console.WriteLine(...)` (маленькая c) | C# — регистрозависимый | `Console` с большой C |
| Забытые кавычки: `WriteLine(Привет)` | текст обязан быть в кавычках | `WriteLine("Привет")` |
| `WriteLine` вместо `Console.WriteLine` | не сказано, *куда* писать | всегда через `Console.` |

## Тест — проверь себя

**Вопрос 1.** Что делает команда `Console.WriteLine("Привет");`?
- A) Спрашивает у пользователя что-то.
- B) Выводит текст «Привет» на экран и переходит на новую строку.
- C) Сохраняет слово «Привет» в памяти.

✅ **Верно: B.**
Почему: `WriteLine` — «напиши строку». `Console.` указывает, что действие происходит на экране.
Почему неверны остальные:
- A — Это делает `Console.ReadLine()` (считывание), а не `WriteLine` (вывод).
- C — Сохранение в памяти — это переменная (следующий урок), а не вывод на экран.

**Вопрос 2.** Что произойдёт, если убрать `;` в конце команды?
- A) Ничего, программа всё равно заработает.
- B) Компилятор покажет ошибку: он не поймёт, где закончился шаг.
- C) Программа выведет точку с запятой на экран.

✅ **Верно: B.**
Почему: `;` — маркер конца шага, как точка в конце предложения. Без него компилятор «теряется».
Почему неверны остальные:
- A — Ошибка будет обязательно; `;` не необязательный.
- C — `;` — служебный символ, он не выводится на экран.

**Вопрос 3.** C# и .NET — это одно и то же?
- A) Да, слова-синонимы.
- B) Нет: C# — язык, .NET — платформа, которая выполняет код.
- C) C# — это платформа, а .NET — язык.

✅ **Верно: B.**
Почему: язык (правила написания) и платформа (среда выполнения) — разные вещи, работающие вместе.
Почему неверны остальные:
- A — Они связаны, но это разные сущности.
- C — Наоборот: C# — язык, .NET — платформа.

**Вопрос 4.** Команда `Console.WriteLine("Привет, мир!");` — это:
- A) Переменная.
- B) Рецепт полностью.
- C) Один шаг рецепта (одна команда).

✅ **Верно: C.**
Почему: одна команда — один шаг. Рецепт — это много таких шагов.
Почему неверны остальные:
- A — Переменная — «коробочка» для значения (следующий урок), а не команда вывода.
- B — Одна строка — лишь шаг, а не весь «рецепт» программы.

## Итог урока
- Программа = рецепт; каждая строка = один шаг.
- `Console.WriteLine(...)` — показать текст.
- `;` — знак конца шага.
- Учись читать ошибки компилятора — они подсказывают, что исправить.
