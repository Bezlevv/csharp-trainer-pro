# Урок 02. Ввод и вывод

## Цель
Научиться «разговаривать» с программой: выводить текст и считывать то, что вводит пользователь.

## Теория «как для ребёнка»

### Консоль — телеграм-переписка с компьютером
Программа и пользователь общаются через консоль (тёмное окно):
- Ты **шлёшь сообщение** компьютеру → `Console.WriteLine("...")`.
- Компьютер **спрашивает тебя** → `Console.ReadLine()`.
- Он **ждёт, пока ты напишешь и нажмёшь Enter**.

### Ввод: `Console.ReadLine()`
```csharp
string name = Console.ReadLine();
```
Команда ждёт, пока пользователь введёт текст и нажмёт Enter, и кладёт введённое в коробочку `name`.

> `Console.ReadLine()` всегда возвращает строку (`string`). Даже если человек ввел число, с точки зрения программы это пока текст.

### Склейка строк и интерполяция
Есть два способа собрать фразу из переменных:

1. Склейка через `+`:
```csharp
Console.WriteLine("Привет, " + name + "!");
```
2. Интерполяция через `$"..."` (удобнее):
```csharp
Console.WriteLine($"Привет, {name}!");
```
`{name}` — место, куда подставится значение переменной `name`.

### Что если пользователь ввёл число?
`Console.ReadLine()` вернёт текст. Если нужно число — превращаем текст в число:
```csharp
int age = int.Parse(Console.ReadLine());
```
Но если человек введёт «пять», программа упадёт. Безопаснее `int.TryParse` — об этом в уровне 1. Пока просто знай про `int.Parse`.

## Примеры

```csharp
Console.Write("Как тебя зовут? ");   // Write — без перехода на новую строку
string name = Console.ReadLine();
Console.WriteLine($"Рад познакомиться, {name}!");
```

```
Как тебя зовут? Анна
Рад познакомиться, Анна!
```

Чем `Write` отличается от `WriteLine`? `Write` не переносит курсор на новую строку. Поэтому вопрос и ответ оказываются на одной строке.

## Сделай сам (задачи с подсказками)

1. Спроси любимый цвет и выведи «Твой любимый цвет: ...».
   *Подсказка: `string color = Console.ReadLine();` затем `WriteLine($"... {color}")`.*
2. Спроси имя и возраст; выведи «Иван, тебе 25 лет».
   *Подсказка: возраст придётся превратить в число: `int.Parse(Console.ReadLine())`.*
3. Выведи вопрос и ответ на одной строке (используй `Write`).
   *Подсказка: `Console.Write("Сколько тебе лет? ");` без `Line`.*
4. Спроси город и страну, выведи: «Я живу в городе ... в стране ...».
   *Подсказка: две переменные и одна интерполяция с двумя `{}`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `Console.WriteLine()` без текста внутри и без скобок | скобки обязательны | `Console.WriteLine("...")` |
| `Console.ReadLine` без скобок | это метод — нужны `()` | `Console.ReadLine()` |
| `Console.WriteLine($"{name}")` без `$` | подстановка не сработает | `$"..."` с `$` перед строкой |
| `int.Parse(Console.ReadLine())` ввёл «пять» | упадёт на тексте | пока оставь `int.Parse`, но помни про риск |

## Тест — проверь себя

**Вопрос 1.** Что делает `string name = Console.ReadLine();`?
- A) Выводит имя на экран.
- B) Ждёт, пока пользователь введёт текст, и кладёт его в `name`.
- C) Создаёт новую строку с текстом «name».

✅ **Верно: B.**
Почему: `ReadLine` считывает ввод и возвращает его; мы кладём результат в переменную.
Почему неверны остальные:
- A — Вывод делает `WriteLine`, а не `ReadLine`.
- C — В переменную попадает то, что ввёл пользователь, а не слово «name».

**Вопрос 2.** Что выведет код?
```csharp
string city = "Казань";
Console.WriteLine($"Город: {city}");
```
- A) `Город: city`
- B) `Город: Казань`
- C) `Город: {city}`

✅ **Верно: B.**
Почему: `$` + `{city}` подставляют *значение* переменной (Казань).
Почему неверны остальные:
- A — Без `$` такая подстановка не работает, но здесь `$` стоит — значит, значение.
- C — `{city}` — это шаблон, который заменяется значением.

**Вопрос 3.** Чем `Console.Write` отличается от `Console.WriteLine`?
- A) Ничем, они одинаковы.
- B) `Write` не переходит на новую строку после вывода, а `WriteLine` — переходит.
- C) `Write` выводит только числа.

✅ **Верно: B.**
Почему: разница только в переносе строки после вывода.
Почему неверны остальные:
- A — Разница есть (перенос строки).
- C — `Write` выводит что угодно, не только числа.

**Вопрос 4.** `Console.ReadLine()` всегда возвращает:
- A) `int` — число.
- B) `double` — дробное число.
- C) `string` — строку.

✅ **Верно: C.**
Почему: ввод с консоли по умолчанию — это текст (строка).
Почему неверны остальные:
- A, B — Чтобы получить число, надо превратить строку (`int.Parse`), но сам `ReadLine` возвращает строку.

## Итог урока
- `Console.WriteLine` / `Console.Write` — показать текст.
- `Console.ReadLine()` — считать ввод пользователя.
- Интерполяция `$"..."` + `{переменная}` — самый удобный способ собрать фразу.
- Ввод — всегда строка; числа приходится «конвертировать».
