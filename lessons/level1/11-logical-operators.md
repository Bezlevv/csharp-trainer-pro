# Урок 11. Логические операторы

## Цель
Научиться строить сложные условия из простых: «и», «или», «не».

## Теория «как для ребёнка»

### Как соединить два условия?
«Взять зонт, если идёт дождь **И** дует сильный ветер». Здесь два условия, соединённые словом «И». В C# «И» — это `&&`.

| Оператор | Что значит | Пример |
|---|---|---|
| `&&` | «и» — оба условия должны быть верны | `age >= 18 && age < 65` |
| `\|\|` | «или» — хотя бы одно верно | `day == "Сб" \|\| day == "Вс"` |
| `!` | «не» — отрицание | `!isAdmin` |

### `&&` — «и»
`( age >= 18 && age < 65 )` верно, только если **оба** условия истинны. Если хоть одно ложно — всё условие ложно.

Пример: «взрослый трудоспособный возраст» = от 18 до 65 (не включая 65).

### `||` — «или»
`( day == "Сб" || day == "Вс" )` верно, если **хотя бы одно** истинно. Дождик, выходной в субботу — правда, в воскресенье — правда, в понедельник — ложь.

### `!` — «не»
`!isAdmin` — «не админ». Инвертирует: было `true` → стало `false`, и наоборот.

## Примеры

```csharp
int age = 30;
bool isStudent = false;

if (age >= 18 && age < 65)
{
    Console.WriteLine("Взрослый трудоспособный возраст");
}

if (age < 18 || isStudent)
{
    Console.WriteLine("Есть скидка");
}
```

## Сделай сам (задачи с подсказками)

1. Спроси возраст: выведи «можно водить машину», если возраст от 18 до 100.
   *Подсказка: `age >= 18 && age <= 100`.*
2. Спроси день недели: выведи «выходной», если суббота или воскресенье.
   *Подсказка: `day == "Сб" || day == "Вс"`.*
3. Спроси число: выведи «в диапазоне», если оно от 10 до 20 включительно.
   *Подсказка: `n >= 10 && n <= 20`.*
4. Есть флаг `bool isBanned`. Выведи «доступ разрешён», если НЕ забанен.
   *Подсказка: `if (!isBanned)`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `18 < age < 65` | C# не умеет двойные сравнения | `age >= 18 && age < 65` |
| `age >= 18 && age < 65` без скобок | при смешении операторов — читаемость | ставь скобки: `(age >= 18) && (age < 65)` |
| `day == "Сб" || day == "Вс"` всего один знак `=` | `=` присваивает | используй `==` |
| `!isBanned = true` | нельзя присваивать рядом с `!` | просто `!isBanned` |

## Тест — проверь себя

**Вопрос 1.** При каких значениях условие `n >= 5 && n <= 10` истинно?
- A) Только при n = 5.
- B) При n от 5 до 10 включительно.
- C) При любом n больше 10.

✅ **Верно: B.**
Почему: `&&` требует, чтобы оба условия были верны: n ≥ 5 и n ≤ 10 одновременно → диапазон 5–10.
Почему неверны остальные:
- A — Верно не только для 5, но и для 6,7,8,9,10.
- C — При n > 10 второе условие `n <= 10` ложно.

**Вопрос 2.** Когда `day == "Сб" || day == "Вс"` ложно?
- A) Когда day — суббота.
- B) Когда day — воскресенье.
- C) Когда day — любой другой день.

✅ **Верно: C.**
Почему: `||` истинно, если хотя бы одно верно. Ложно, только когда оба неверны — это любой день, кроме субботы и воскресенья.
Почему неверны остальные:
- A, B — В эти дни условие истинно.

**Вопрос 3.** Что делает `!isAdmin`?
- A) Проверяет, что isAdmin истинно.
- B) Инвертирует: true становится false и наоборот.
- C) Делает isAdmin всегда истинным.

✅ **Верно: B.**
Почему: `!` — отрицание.
Почему неверны остальные:
- A — `!` делает противоположное, а не повторяет.
- C — Ничего не «всегда истинным» не делается.

**Вопрос 4.** Выбери правильную запись: «age от 18 до 65, не включая 65»:
- A) `age >= 18 && age < 65`
- B) `age >= 18 || age < 65`
- C) `age == 18 && age == 65`

✅ **Верно: A.**
Почему: «и» (оба условия), причём верхняя граница строгая (`< 65`).
Почему неверны остальные:
- B — `||` означало бы «или», а это почти всегда верно, это не то.
- C — `==` оба сразу не могут быть истинны (18 ≠ 65).

## Итог урока
- `&&` — «и» (оба верны).
- `||` — «или» (хотя бы одно верно).
- `!` — «не» (отрицание).
- Для диапазонов используй `&&` и явные границы.
