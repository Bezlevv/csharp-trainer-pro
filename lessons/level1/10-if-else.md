# Урок 10. Условия if/else

## Цель
Научиться заставлять программу принимать решения: что-то делать только при определённом условии.

## Теория «как для ребёнка»

### Развилка на дороге
Представь, что ты подошёл к развилке. Если идёт дождь — возьми зонт. Если нет — иди без зонта. Это и есть `if` (если) и `else` (иначе).

```csharp
if (age >= 18)
{
    Console.WriteLine("Ты взрослый");
}
else
{
    Console.WriteLine("Ты ещё несовершеннолетний");
}
```

Читается: «**если** возраст ≥ 18 — вывести одно, **иначе** — другое».

### Как пишется
- После `if` — скобки с условием: `if (условие)`.
- Внутри фигурных скобок `{ }` — что делать, если условие истинно.
- `else` — необязателен: если он не нужен, можно его не писать.

### Что такое «условие»?
Условие — это выражение, которое даёт «да/нет» (тип `bool`):

| Сравнение | Что значит |
|---|---|
| `a == b` | a равно b |
| `a != b` | a не равно b |
| `a > b` | a больше b |
| `a < b` | a меньше b |
| `a >= b` | a больше или равно b |
| `a <= b` | a меньше или равно b |

> `==` — это проверка равенства. А одинарный `=` — это присваивание (положить значение). Не путай!

### Вложенные условия
Условие может быть внутри другого условия. Но лучше не увлекаться — код становится трудно читать.

## Примеры

```csharp
Console.Write("Сколько тебе лет? ");
int age = int.Parse(Console.ReadLine());

if (age >= 18)
{
    Console.WriteLine("Доступ разрешён");
}
else
{
    Console.WriteLine("Доступ запрещён");
}
```

## Сделай сам (задачи с подсказками)

1. Спроси число; выведи «положительное», «отрицательное» или «ноль».
   *Подсказка: сначала `if (n > 0)`, потом `else if (n < 0)`, затем `else`.*
2. Спроси число; выведи, чётное ли оно.
   *Подсказка: `n % 2 == 0` — чётное.*
3. Спроси оценку: если ≥ 4 — «молодец», иначе — «нужно подтянуть».
   *Подсказка: `if (score >= 4)`.*
4. Спроси возраст: если < 7 — «садик», < 18 — «школа», иначе — «взрослая жизнь».
   *Подсказка: цепочка `if / else if / else`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `if (age = 18)` | одинарный `=` присваивает, а не сравнивает | `if (age == 18)` |
| `if age >= 18` без скобок | условие обязательно в `()` | `if (age >= 18)` |
| `if (age >= 18);` | `;` после условия «обрезает» ветку | после `)` сразу `{` |
| Забыл `{ }` | выполнится только первая строка | всегда ставь `{ }` |

## Тест — проверь себя

**Вопрос 1.** Что выведет код?
```csharp
int x = 5;
if (x > 10) Console.WriteLine("большое");
else Console.WriteLine("маленькое");
```
- A) `большое`
- B) `маленькое`
- C) ничего

✅ **Верно: B.**
Почему: 5 не больше 10, значит условие ложно → выполняется ветка `else`.
Почему неверны остальные:
- A — Условие `x > 10` ложно, так что эта ветка пропускается.
- C — `else` всегда выполнится, поэтому вывод будет обязательно.

**Вопрос 2.** Что означает `a == b`?
- A) Положить b в коробочку a.
- B) Проверить, равны ли a и b.
- C) Сложить a и b.

✅ **Верно: B.**
Почему: двойное `==` — проверка равенства.
Почему неверны остальные:
- A — Присваивание — это одинарное `=`.
- C — Сложение — это `+`.

**Вопрос 3.** Как сделать проверку: «если число отрицательное, вывести предупреждение» (и ничего иначе)?
- A) `if (n < 0) { Console.WriteLine("Отрицательное"); }`
- B) `if (n < 0) Console.WriteLine("Отрицательное"); else Console.WriteLine("ОК");`
- C) `Console.WriteLine("Отрицательное"); if (n < 0)`

✅ **Верно: A.**
Почему: условие с блоком `{ }`, `else` не обязателен — если его нет, при ложном условии просто ничего не происходит.
Почему неверны остальные:
- B — Здесь `else` выводит «ОК», а по условию задачи этого быть не должно.
- C — Сначала выполняется вывод, проверка — позже и бессмысленно.

**Вопрос 4.** Что выведет код?
```csharp
int n = 0;
if (n > 0) Console.WriteLine("+");
else if (n < 0) Console.WriteLine("-");
else Console.WriteLine("0");
```
- A) `+`
- B) `-`
- C) `0`

✅ **Верно: C.**
Почему: 0 не больше 0 и не меньше 0 → срабатывает финальный `else`.
Почему неверны остальные:
- A — `n > 0` ложно для нуля.
- B — `n < 0` тоже ложно для нуля.

## Итог урока
- `if (условие) { ... }` — если условие верно, выполнить блок.
- `else { ... }` — иначе (необязателен).
- Сравнения: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- Не путай `==` (сравнить) и `=` (присвоить).
