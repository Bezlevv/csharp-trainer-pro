# Урок 13. Цикл for

## Цель
Научиться повторять действия заранее известное число раз.

## Теория «как для ребёнка»

### Карусель
`for` — это карусель: ты заранее знаешь, сколько кругов надо проехать.

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine($"Круг номер {i}");
}
```

Разбор трёх частей в скобках:

| Часть | Что делает | Пример |
|---|---|---|
| `int i = 1;` | старт (счётчик начинает с 1) | счётчик |
| `i <= 5;` | условие продолжения | крутимся, пока i ≤ 5 |
| `i++` | шаг после каждого круга | i увеличивается на 1 |

Работает так:
1. Делаем старт: `i = 1`.
2. Проверяем условие: `1 <= 5` → да → выполняем тело.
3. Выполняем `i++` → теперь `i = 2`.
4. Снова проверяем условие — и так, пока оно истинно.

### Шаблон «ровно N раз»
Самый частый случай — повторить ровно N раз:

```csharp
for (int i = 0; i < 10; i++)
{
    // выполнится 10 раз: i = 0,1,...,9
}
```

Обрати внимание: счётчик идёт **от 0 до N-1**. Так принято в программировании.

## Примеры

**Сумма чисел от 1 до 100:**
```csharp
int sum = 0;
for (int i = 1; i <= 100; i++)
{
    sum += i;
}
Console.WriteLine(sum);
```

**Чётные числа до 20:**
```csharp
for (int i = 0; i <= 20; i += 2)
{
    Console.WriteLine(i);
}
```

## Сделай сам (задачи с подсказками)

1. Выведи числа от 1 до 10.
   *Подсказка: `for (int i = 1; i <= 10; i++)`.*
2. Выведи числа от 10 до 1 (убывание).
   *Подсказка: `for (int i = 10; i >= 1; i--)` — шаг вниз.*
3. Вычисли сумму чисел от 1 до N (N спрашиваешь).
   *Подсказка: `sum += i;` внутри цикла.*
4. Выведи квадраты чисел от 1 до 10.
   *Подсказка: `Console.WriteLine(i * i);`.*
5. Выведи «звёздочки»: 5 штук в одну строку.
   *Подсказка: внутри цикла используй `Console.Write("*")` (без Line), после цикла — `Console.WriteLine()`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `for (int i = 1; i <= 10; i++)` но с `;` после скобок | пустое тело, цикл просто «крутится» | не ставь `;` сразу после `)` |
| `i < 10` и ждёшь 10 повторов | будет ровно 10 (0..9) | если нужно 10 — `i < 10` |
| Забыл `i++` | бесконечный цикл | всегда пиши шаг |
| `i` используешь после цикла | переменная живёт только внутри цикла | объяви счётчик вне цикла, если нужен потом |

## Тест — проверь себя

**Вопрос 1.** Сколько раз выполнится тело?
```csharp
for (int i = 0; i < 5; i++) { }
```
- A) 4
- B) 5
- C) 6

✅ **Верно: B.**
Почему: i идёт 0,1,2,3,4 — ровно 5 значений меньше 5.
Почему неверны остальные:
- A — 4 было бы при `i < 4` или `i <= 3`.
- C — 6 было бы при `i < 6`.

**Вопрос 2.** Что выведет код?
```csharp
for (int i = 1; i <= 3; i++) Console.WriteLine(i);
```
- A) `1 2 3`
- B) `0 1 2`
- C) `1 2`

✅ **Верно: A.**
Почему: начинает с 1, идёт до 3 включительно (`<=`).
Почему неверны остальные:
- B — Это было бы при старте с 0.
- C — 2 — это при `i < 3` (без включения 3), а у нас `<=`.

**Вопрос 3.** Что делает `i += 2` в шаге цикла?
- A) Увеличивает i на 2 каждый раз.
- B) Увеличивает i на 1.
- C) Уменьшает i на 2.

✅ **Верно: A.**
Почему: `+= 2` — «прибавь 2».
Почему неверны остальные:
- B — Прибавка на 1 — это `i++` или `i += 1`.
- C — Уменьшение — это `i -= 2`.

**Вопрос 4.** Чем опасен цикл без изменения счётчика (`i++`)?
- A) Ничем.
- B) Он станет бесконечным (условие никогда не станет ложным).
- C) Он выполнится один раз.

✅ **Верно: B.**
Почему: без шага i не меняется, условие остаётся истинным навсегда.
Почему неверны остальные:
- A — Это серьёзная ошибка.
- C — Один раз не выполнится — он зациклится.

## Итог урока
- `for` — повторение известное число раз.
- Три части: старт, условие, шаг.
- Счётчик от 0 до N-1 — стандарт.
- Не забывай шаг (`i++`), иначе цикл бесконечный.
