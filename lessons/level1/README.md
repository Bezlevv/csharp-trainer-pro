# Уровень 1 — Junior Starter

Ты уже умеешь выводить текст, читать ввод и считать. Теперь научим компьютер **принимать решения** и **повторять действия** — без этого любая реальная программа невозможна.

## Как заниматься
Читай теорию → набирай примеры → решай задачи (подсказка внутри) → смотри разбор ошибок → проходи тест в конце. Каждый ответ теста разобран: почему верный и почему остальные нет.
