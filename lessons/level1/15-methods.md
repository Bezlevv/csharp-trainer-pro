# Урок 15. Методы

## Цель
Научиться упаковывать кусочки кода в «инструкции с именем» и переиспользовать их.

## Теория «как для ребёнка»

### Инструкция с именем
Представь, что ты записал на бумажке рецепт «как пожарить яйцо» и повесил на холодильник с надписью **ПожаритьЯйцо**. Теперь ты можешь говорить «ПожаритьЯйцо!» вместо того, чтобы повторять все шаги заново. Это и есть метод.

```csharp
void SayHello()
{
    Console.WriteLine("Привет!");
}
```

Вызов:
```csharp
SayHello();   // "Привет!"
SayHello();   // ещё раз
```

### Метод с параметрами (входными данными)
Метод умеет принимать данные:
```csharp
void Greet(string name)
{
    Console.WriteLine($"Привет, {name}!");
}
```

Вызов:
```csharp
Greet("Маша");   // "Привет, Маша!"
Greet("Петя");   // "Привет, Петя!"
```

### Метод, возвращающий результат
Некоторые методы не просто печатают, а возвращают значение (как «выдающий сдачу» автомат) — тип возврата пишется вместо `void`:

```csharp
double Square(double x)
{
    return x * x;
}
```

Вызов и использование результата:
```csharp
double result = Square(5);   // result = 25
Console.WriteLine(result);
```

- `void` — метод ничего не возвращает.
- `double`/`int`/`string` и т.д. — возвращает значение этого типа.
- `return` — вернуть значение и закончить метод.

### Зачем это нужно
1. **Не повторяться** — написал один раз, зовёшь много раз.
2. **Смысл** — имя метода объясняет, что он делает.
3. **Чистый код** — большую задачу дробишь на маленькие методы.

## Примеры

```csharp
int Add(int a, int b) => a + b;   // сокращённая запись (expression-bodied)

// использование:
Console.WriteLine(Add(2, 3));      // 5
Console.WriteLine(Add(10, 5));     // 15
```

## Сделай сам (задачи с подсказками)

1. Напиши метод `PrintHeader()` — выводит «====» и текст. Вызови его 3 раза.
   *Подсказка: `void PrintHeader() { ... }` — без параметров.*
2. Напиши метод `Square(double x)`, возвращающий x². Выведи `Square(5)`.
   *Подсказка: `double Square(double x) => x * x;`*
3. Напиши метод `Max(int a, int b)` — возвращает большее из двух.
   *Подсказка: `return a > b ? a : b;` (тернарный оператор).*
4. Напиши метод `IsEven(int n)` — возвращает `bool`.
   *Подсказка: `return n % 2 == 0;`*
5. Метод `Describe(int age)` выводит «ребёнок», «подросток» или «взрослый».
   *Подсказка: внутри метода используй `if/else`.*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| Метод возвращает значение, но нет `return` | компилятор не увидит результата | добавь `return ...;` |
| `void`-метод с `return 5;` | нечего возвращать | убери значение или смени тип на `int` |
| Вызов `Square` без `()` | это вызов метода — нужны скобки | `Square(5)` |
| Имя метода с маленькой буквы | методы — в PascalCase | `Square`, `Greet` |

## Тест — проверь себя

**Вопрос 1.** Что выведет код?
```csharp
void Print(int n) { Console.WriteLine(n); }
Print(7);
```
- A) `n`
- B) `7`
- C) Ошибку

✅ **Верно: B.**
Почему: Print(7) передаёт 7 в параметр n и выводит его значение.
Почему неверны остальные:
- A — Выводится значение, а не имя параметра.
- C — Всё корректно.

**Вопрос 2.** Что означает тип `void`?
- A) Метод возвращает число.
- B) Метод ничего не возвращает.
- C) Метод возвращает строку.

✅ **Верно: B.**
Почему: `void` — «пусто», метод выполняет действия, но ничего не возвращает.
Почему неверны остальные:
- A, C — Это были бы `int`, `double`, `string` и т.п.

**Вопрос 3.** Что вернёт `Square(4)`?
```csharp
double Square(double x) => x * x;
```
- A) 8
- B) 16
- C) 4

✅ **Верно: B.**
Почему: 4 × 4 = 16.
Почему неверны остальные:
- A — 8 — это 2×4 (умножение на 2), а не квадрат.
- C — 4 — это входное значение, не результат.

**Вопрос 4.** В чём польза методов?
- A) Чтобы код был длиннее.
- B) Чтобы не повторять один и тот же код и давать блокам понятные имена.
- C) Чтобы программа стала красивее, но не работала.

✅ **Верно: B.**
Почему: методы убирают дублирование и добавляют смысл.
Почему неверны остальные:
- A — Длиннее — не цель, важно качество.
- C — Методы — это про работоспособность и читаемость, а не украшение.

## Итог урока
- Метод — поименованная инструкция, которую можно звать много раз.
- Параметры — входные данные; `return` — результат.
- `void` — ничего не возвращает.
- Пиши методы в PascalCase, смыслово.
