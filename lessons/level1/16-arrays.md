# Урок 16. Массивы

## Цель
Научиться хранить много значений в одной «коробке с клетками» и перебирать их.

## Теория «как для ребёнка»

### Коробка с клетками
Массив — это коробка, разделённая на пронумерованные клетки. Номер клетки называется **индексом**, и нумерация начинается с **0**.

```csharp
int[] numbers = { 10, 20, 30 };
```

Теперь:
- `numbers[0]` — первая клетка (значение 10);
- `numbers[1]` — вторая клетка (значение 20);
- `numbers[2]` — третья клетка (значение 30).

### Как создать массив
```csharp
// с готовыми значениями:
int[] a = { 1, 2, 3 };

// пустой с заданным размером:
string[] names = new string[5];
```

### Длина массива
```csharp
Console.WriteLine(numbers.Length);   // 3
```

### Перебор через цикл
```csharp
int[] numbers = { 10, 20, 30 };

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}
```

Или `foreach` — «для каждого элемента» (не нужно думать об индексах):
```csharp
foreach (int n in numbers)
{
    Console.WriteLine(n);
}
```

### Изменить элемент
```csharp
numbers[1] = 99;   // теперь { 10, 99, 30 }
```

## Примеры

**Сумма элементов:**
```csharp
int[] numbers = { 4, 7, 2 };
int sum = 0;
foreach (int n in numbers) sum += n;
Console.WriteLine(sum);   // 13
```

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| `numbers[3]` при длине 3 | индексы идут 0,1,2 — 3 уже за границей | помни: последний индекс = длина − 1 |
| `{ 1, 2, 3 }` без типа | C# не поймёт тип | укажи тип: `int[] numbers = { ... };` |
| Цикл `i <= numbers.Length` | выход за границу (IndexOutOfRangeException) | используй `i < numbers.Length` |
| `int[] numbers = new int[3];` и сразу `numbers[0]` | значение по умолчанию 0 | 0 — значение по умолчанию для int, это нормально |

## Тест — проверь себя

**Вопрос 1.** Какое значение у `numbers[1]`?
```csharp
int[] numbers = { 10, 20, 30 };
```
- A) 10
- B) 20
- C) 30

✅ **Верно: B.**
Почему: индексы с 0: numbers[0]=10, numbers[1]=20, numbers[2]=30.
Почему неверны остальные:
- A — 10 — это numbers[0].
- C — 30 — это numbers[2].

**Вопрос 2.** Чему равна длина `{ 1, 2, 3, 4 }`?
- A) 3
- B) 4
- C) 5

✅ **Верно: B.**
Почему: четыре элемента → Length = 4.
Почему неверны остальные:
- A — 3 — это был бы массив из трёх элементов.
- C — 5 — это был бы массив из пяти элементов.

**Вопрос 3.** Какой индекс последнего элемента массива длиной 5?
- A) 5
- B) 4
- C) 6

✅ **Верно: B.**
Почему: индексы с 0, последний = длина − 1 = 4.
Почему неверны остальные:
- A — 5 — это длина, а не индекс последнего.
- C — 6 — вообще за границей.

**Вопрос 4.** Что выведет код?
```csharp
int[] a = { 2, 4, 6 };
int s = 0;
foreach (int x in a) s += x;
Console.WriteLine(s);
```
- A) 12
- B) 6
- C) 2

✅ **Верно: A.**
Почему: 2 + 4 + 6 = 12.
Почему неверны остальные:
- B — 6 — это просто последний элемент.
- C — 2 — это первый элемент.

## Итог урока
- Массив — упорядоченная «коробка с клетками»; индексы с 0.
- `Length` — число элементов.
- `foreach` — удобный перебор всех элементов.
- Последний индекс всегда `Length - 1`; не выходи за границы.
