# Урок 12. switch — выбор по вариантам

## Цель
Научиться выбирать действие, когда вариантов несколько и каждый зависит от одного значения.

## Теория «как для ребёнка»

### Когда нужен switch?
Если у тебя есть одно значение (например, день недели) и для каждого значения — свой ответ, можно писать длинную цепочку `if`. Но удобнее и читаемее использовать `switch`.

### Классический switch
```csharp
string day = Console.ReadLine() ?? "";

switch (day)
{
    case "Пн":
        Console.WriteLine("Начало недели");
        break;
    case "Сб":
    case "Вс":
        Console.WriteLine("Выходной");
        break;
    default:
        Console.WriteLine("Не знаю такой день");
        break;
}
```

Как читать:
- `case "Пн"` — «если day равно "Пн"»;
- `break;` — «выйти из switch» (иначе код «провалится» дальше);
- несколько `case` подряд без кода — несколько значений попадают в один блок;
- `default` — «во всех остальных случаях» (как `else`).

### Сокращённый вариант — switch-выражение
```csharp
string message = day switch
{
    "Пн" => "Начало недели",
    "Сб" or "Вс" => "Выходной",
    _ => "Не знаю такой день"
};
```
- `=>` — «то-то»;
- `or` — «или»;
- `_` — «все остальные случаи».

## Примеры

```csharp
int month = 3;
string season = month switch
{
    12 or 1 or 2 => "Зима",
    3 or 4 or 5 => "Весна",
    6 or 7 or 8 => "Лето",
    9 or 10 or 11 => "Осень",
    _ => "Неверный месяц"
};
Console.WriteLine(season);
```

## Сделай сам (задачи с подсказками)

1. Спроси номер дня недели (1–7), выведи его название.
   *Подсказка: `switch (dayNumber)` с `case 1:` ... `case 7:`.*
2. Спроси уровень доступа («user», «manager», «admin»); выведи, что доступно.
   *Подсказка: `case "user":` — «только чтение» и т.д.*
3. Спроси страну; выведи столицу.
   *Подсказка: `case "Россия": Console.WriteLine("Москва"); break;` и т.д.*
4. Перепиши задачу 3 через switch-выражение с `=>` и `_`.
   *Подсказка: `string capital = country switch { "Россия" => "Москва", _ => "не знаю" };`*

## Разбор типичных ошибок

| Ошибка | Что не так | Как правильно |
|---|---|---|
| Забыл `break;` | код «провалится» в следующий case | всегда `break;` в конце блока |
| `case "Пн";` вместо `:` | после значения — двоеточие | `case "Пн":` |
| `default` поставлен не последним | порядок нарушен | `default` — в конце |
| Сравнение с `=` | `=` присваивает | в `case` уже сравнение, `=` не нужен |

## Тест — проверь себя

**Вопрос 1.** Что выведет код?
```csharp
string color = "красный";
switch (color)
{
    case "зелёный": Console.WriteLine("Идти"); break;
    case "красный": Console.WriteLine("Стоять"); break;
    default: Console.WriteLine("Осторожно"); break;
}
```
- A) `Идти`
- B) `Стоять`
- C) `Осторожно`

✅ **Верно: B.**
Почему: color равен «красный», значит срабатывает `case "красный"`.
Почему неверны остальные:
- A — «зелёный» не совпал.
- C — `default` срабатывает только если ни один `case` не совпал.

**Вопрос 2.** Зачем нужен `break;`?
- A) Чтобы завершить программу.
- B) Чтобы выйти из switch после выполнения выбранной ветки.
- C) Чтобы пропустить default.

✅ **Верно: B.**
Почему: `break` останавливает выполнение switch после найденной ветки.
Почему неверны остальные:
- A — Программа продолжает работать дальше после switch.
- C — `break` не про `default`, а про выход из switch.

**Вопрос 3.** Что означает `_` в switch-выражении?
- A) Ничего, это опечатка.
- B) «Все остальные случаи» (по умолчанию).
- C) «И» (как &&).

✅ **Верно: B.**
Почему: `_` — дискард, «любое другое значение».
Почему неверны остальные:
- A — Это законный синтаксис.
- C — «И» — это `and`/`&&`, а не `_`.

**Вопрос 4.** Что выведет код?
```csharp
int n = 2;
string s = n switch
{
    1 => "один",
    2 => "два",
    _ => "много"
};
Console.WriteLine(s);
```
- A) `один`
- B) `два`
- C) `много`

✅ **Верно: B.**
Почему: n = 2 → подходит ветка `2 => "два"`.
Почему неверны остальные:
- A — Для 1 была бы ветка 1, но у нас 2.
- C — `_` срабатывает только для значений, не совпавших с 1 и 2.

## Итог урока
- `switch` — выбор из нескольких вариантов по одному значению.
- `break;` — обязателен в классическом switch.
- `default` (или `_`) — «все остальные случаи».
- switch-выражение с `=>` и `or` — компактнее.
